# Converter

Converts features of a TypeScript game (the source) into the architecture of the Godot + C++ game (the target),
and audits code for wrong methodologies. It never writes to the target game: it reads it, and everything it makes
goes to an output folder. Paths are always given on the command line or in a configuration file.

## Stages

| Command | What it does |
|---|---|
| `graph` | Traces a feature (or the whole source) through the source's own type checker: every declaration it uses, typed edges, external APIs, patterns, fingerprints. |
| `cppgraph` | The same graph for the target's C++, through clangd. |
| `audit` | Runs the methodology catalog over a graph: each finding says what is wrong, the correct methodology, its form in the target, and the primary sources. |
| `classify` | What a feature becomes in the target: roles from facts, mapped dependencies, what still blocks it. |
| `translate` | Writes a feature as C++ in its owner folder (types, API, edits, queries, indexes); refuses when anything cannot be translated. |
| `differential` | Runs the translation and its source on the same random scenario and compares them (a double build that must agree exactly, and the target's float build). |
| `package` | The translation as a conversion package: its files, its registration where the target's gates look, its state member. |
| `sandbox` | Tests a conversion package in an isolated clone of the target: the target's own setup and verification before and after the package; prints the manual integration. |
| `baseline` | The target's own setup and verification on its base alone, which proves a sandbox configuration. |

Run with Node 23.6 or newer: `node src/cli.ts <command> --flag value`.

## A conversion package

One feature, stored outside the target:

- `manifest.json`: the source commit and the SHA-256 of every source file read, the target's base commit, the
  converter's commit (packaging refuses a converter with uncommitted changes) and the identity of the commits.
- `patches/`: the conversion as a series of commits, one per topic, each compiling alone (`git format-patch`).
- `evidence/`: every log and photo of the sandbox, before and after.

Integration into the target is manual: the sandbox prints the commands (fetch the reviewed branch, a worktree,
the target's usual integration checks). Nothing integrates by itself.

## Rules the conversion follows

The target's `CLAUDE.md` and gate rules are the authority; these are how the converter applies them.

1. **One owner per feature.** A feature is converted into the subsystem that owns it (one folder), entering the
   target only through the points the architecture designates: its state as a member of `CityState`, its time step
   called by `Simulation::tick`, the player's actions as `sim/commands`, its tunables in `data/**` with a schema read
   by `DataTables`, its drawing in `render/` (read only), its changes announced in the `ChangeLog`. No feature code is
   written into another owner's files.
2. **What another owner must provide is that owner's work.** When a feature needs a capability its neighbour does
   not offer yet, the package names it and is not complete; the converter never writes it into the neighbour, and
   never leaves a declaration without an implementation.
3. **Roles come from each unit's facts, not from its folder.** A source unit that mixes responsibilities (input,
   state, simulation, drawing) is split by responsibility; it is never carried over whole.
4. **Every constant needs a source.** A value moved into `data/**` carries where it came from; the package lists each
   one and is complete only when each has a measurement or a primary source.
5. **The correct methodology is written every time.** Each pattern of the audit catalog is converted to its correct
   form (instancing, reused buffers, a spatial index, a ring buffer, state in its owner), whatever its static rating.
6. **The target's gates judge the result** in the sandbox, with its build, tests and photos.

## How a translation decides types

What each value is in C++ has one owner, the flow of values (`src/translate/flow.ts`): every place a value lives is
a slot, every way it moves is a flow, and three facts per slot (integer or real, owned or referenced, which struct
shape) are solved together to a fixpoint. The type mapper and the emitters only read that solution. A spec
(`configs/<feature>.translate.json`) says what the translator may not guess: the owner folder, the state and its
member, which names are integers, the target's types and owned concepts (patterns), the names of literals the
target's gates forbid, and what stays with other owners.

## Feature

`node src/cli.ts feature --source-root <4.0 root> --entry <file>... --out <dir>` cuts a feature from the whole
program: its own declarations (by dominance: what the program reaches only through it), its slices of shared code
(forward slicing in the program's functions that name it or the state that holds its values), the dictionary
entries, style rules and non-code files it uses, the shared code it uses and where the program plugs it in. What a
call runs comes from the call graph of Jelly (`@cs-au-dk/jelly`, a points-to analysis: `--jelly <package dir>` or
`CONVERTER_JELLY`); style sheets are read with the source's PostCSS (`--postcss`).

## Tests

`CONVERTER_TYPESCRIPT=<typescript package dir> CONVERTER_POSTCSS=<postcss package dir> CONVERTER_JELLY=<jelly package dir>
CONVERTER_CLANGD=<clangd> CONVERTER_CXX=<clang++> node --test "test/**/*.test.ts"`; type check with
`node scripts/typecheck.ts --typescript <dir> --types <node_modules/@types dir>`.

# Converter design: any feature of the source, converted whole, with no decision by hand

The input is a feature: one or more entry points of the source (a file, a symbol). Everything else is decided by
rules from facts of the two programs. A decision the converter cannot make from facts is a defect of the converter,
never a field for a person to fill.

## 1. One model of each program

- **Source:** the whole TypeScript program, opened once with its own compiler. The graph (units, typed edges,
  external APIs) and the flow of values (every slot, every flow) are built over **all** its files, so every call site,
  every caller and every shared helper is known. Equality comparisons are flows both ways (`s.id !== id` makes `id`
  the kind of `s.id`): integer kinds follow from the whole program, never from names.
- **Target:** the game's C++ graph (clangd), its GDScript, its gate rules (layers, limits, allowed numbers, owners,
  map), its data tables and their schemas.
- The flow is solved with a real worklist (each flow re-runs only when a slot it read changed), so the whole program
  solves in time proportional to its size.

## 2. The feature, traced whole

From the entry points, the closure over the graph: every unit reached, in every file. Shared code is part of the
closure; it is translated once, into its own owner, and reused by every feature that reaches it (a second feature
finds it already in the target and links to it).

## 3. Each unit's place in the target, decided by rules

| Decision | Rule |
|---|---|
| Layer | the unit's facts: state, time step, computation → `native/src/sim`; draws (three.js) → `native/src/render` (reads only); interface (DOM) → GDScript in `project/ui` through `CityStore`; tunable values → `project/data` with a schema; GLSL → `.gdshader`; workers → `JobPool` |
| Owner folder | units of one layer grouped by the graph's cohesion (modularization: maximize intra-cluster edges, minimize inter-cluster, TurboMQ), each group a subsystem named after its dominant source module |
| Target type | a source type whose shape (fields and operations) is a target type's (`Vec2 {x, y}` ↔ `V2`) maps to it; otherwise it is translated |
| Target concept | a source function with a candidate in the target of the same signature shape is run against it on generated inputs (differential); equal results → the target's owner is called; otherwise the source's is translated |
| Integer kinds | the solved flow over the whole program |
| Literal names | from the slot or call that receives the literal (`Math.min(20, v)` assigned to `vehicles` → `MAX_VEHICLES`), unique per owner |
| State | the types the feature's edits take and return become a struct held by `CityState`; edits become commands under the exclusive lock; indexes are rebuilt by each edit |
| Registration | layer rule, map line (from the unit's doc comment), state member: written where the gates read them |

## 4. Translation per layer

- **Simulation C++:** the current translator, extended to every construct of the source: classes (fields, methods,
  constructors, inheritance → structs with methods; dynamic dispatch only where the source overrides), generics
  (templates), enums, closures, Map/Set/typed arrays, async and workers (jobs on `JobPool`), exceptions (error results).
- **Render C++:** a fixed catalog from the three.js API to the game's render owners (BufferGeometry → `MeshBuilder`,
  InstancedMesh → MultiMesh through the RenderingServer, materials → the game's shaders and material tables,
  frustum/LOD → the game's streaming); written once, as the translator's library knowledge.
- **Shaders:** parsed with an existing GLSL parser (not a new one), rewritten to Godot's shading language by the
  rules of Godot's official conversion guide.
- **Interface:** DOM and CSS → Godot Controls built through `theme_builder.gd`, texts through `tr()` with the CSV
  catalog, numbers only from `CityStore.snapshot`, actions through `CityStore.dispatch`.

## 5. Proof, for every unit

- Unit tests of each rule, each with a mutation shown to be caught.
- Simulation: differential runs against the source (double build exact, float build within precision).
- Render: the same scene captured in the source and in the target, compared with a perceptual metric.
- Target: the package in an isolated clone with the game's gates, builds, tests, capture and soak.

## 6. Order of work

1. Whole-program model: flow with a worklist over all files; equality flows; no name rules.
2. Whole-feature tracing across files; shared code into its own owner once; emission per owner.
3. Automatic decisions: target types by shape, target concepts by differential equivalence, literal names, owner
   folders by cohesion, map lines from doc comments. The spec shrinks to the entry points.
4. Classes, generics, enums, exceptions; async and workers.
5. Render catalog; shaders; interface.
6. The transit feature whole (network, vehicles, tools, drawing, panel) converted with none of the spec's manual
   fields, proved by every check above.

const MACHINE_KEYS = ['source', 'game', 'ports', 'jelly', 'typescript', 'types', 'postcss', 'mingw', 'clangd', 'cxx', 'godot', 'bash', 'python'] as const;

function fail(message: string): never {
  console.error(`port: ${message}`);
  process.exit(1);
}

/** The machine file with every `${key}` resolved. */
function readMachine(file: string): Machine {
  const raw = JSON.parse(fs.readFileSync(file, 'utf8')) as Record<string, unknown>;
  const resolve = (key: string, seen: readonly string[]): string => {
    const value = raw[key];
    if (typeof value !== 'string') fail(`${file} has no "${key}"`);
    if (seen.includes(key)) fail(`${file}: "${key}" refers to itself`);
    return value.replace(/\$\{(\w+)\}/g, (_m, other: string) => resolve(other, [...seen, key]));
  };
  return Object.fromEntries(MACHINE_KEYS.map((k) => [k, resolve(k, [])])) as Machine;
}

function environment(m: Machine): NodeJS.ProcessEnv {
  return {
    ...process.env, GODOT: m.godot, MINGW: m.mingw, BASH: m.bash, PYTHON: m.python, CONVERTER_JELLY: m.jelly,
    CONVERTER_TYPESCRIPT: m.typescript, CONVERTER_POSTCSS: m.postcss, CONVERTER_CLANGD: m.clangd, CONVERTER_CXX: m.cxx,
  };
}

/** Runs a converter command, its output shown as it comes; returns its exit code. */
function converter(m: Machine, args: readonly string[]): number {
  console.log(`\n> converter ${args.join(' ')}`);
  const run = spawnSync(process.execPath, ['--max-old-space-size=12288', CLI, ...args], { cwd: CONVERTER, env: environment(m), stdio: 'inherit' });
  return run.status ?? 1;
}

function git(dir: string, args: readonly string[]): string {
  const run = spawnSync('git', ['-C', dir, ...args], { encoding: 'utf8', maxBuffer: 256 * 1024 * 1024 });
  if (run.status !== 0) fail(`git ${args.join(' ')} in ${dir}: ${run.stderr.trim()}`);
  return run.stdout;
}

const hash = (...parts: readonly string[]): string => crypto.createHash('sha256').update(parts.join('\0')).digest('hex').slice(0, 16);
const contents = (files: readonly string[]): string => files.map((f) => `${f}\0${fs.readFileSync(f, 'utf8')}`).join('\0');

/** What identifies the source as it is now: its commit, its uncommitted changes and their sizes and times. */
function sourceFingerprint(root: string): string {
  const status = git(root, ['status', '--porcelain', '--untracked-files=all']);
  const changed = status.split(/\r?\n/).filter(Boolean).map((line) => line.slice(3).split(' -> ').at(-1)!.replace(/^"|"$/g, ''));
  const stats = changed.map((file) => {
    const full = path.join(root, file);
    if (!fs.existsSync(full)) return `${file} gone`;
    const s = fs.statSync(full);
    return `${file} ${s.size} ${s.mtimeMs}`;
  });
  return hash(git(root, ['rev-parse', 'HEAD']), status, ...stats);
}

/** The whole program's graph and Jelly's analysis, kept per state of the source and of the converter code that makes them. */
function programCache(m: Machine): { readonly graph: string; readonly jelly: string } {
  const graphCode = fs.readdirSync(path.join(CONVERTER, 'src', 'graph')).map((f) => path.join(CONVERTER, 'src', 'graph', f));
  const dir = path.join(CACHE, `source-${sourceFingerprint(m.source)}`);
  return {
    graph: path.join(dir, `program-${hash(contents(graphCode))}.json`),
    jelly: path.join(dir, `jelly-${hash(contents([path.join(CONVERTER, 'src', 'feature', 'callgraph.ts'), path.join(m.jelly, 'package.json')]))}`),
  };
}

const FEATURE_NAME = /^[a-z0-9][a-z0-9-]*$/;
function featureName(name: string | undefined): string {
  if (!name || !FEATURE_NAME.test(name)) fail(`give a feature name: lower case, digits and dashes (got "${name ?? ''}")`);
  return name;
}

const portDir = (m: Machine, feature: string): string => path.join(m.ports, feature);
const featureDir = (feature: string): string => path.join(FEATURES, feature);

function doctor(m: Machine): number {
  let bad = 0;
  const check = (what: string, ok: boolean, detail: string): void => {
    bad += ok ? 0 : 1;
    console.log(`${ok ? 'ok  ' : 'FAIL'} ${what}: ${detail}`);
  };
  const [major = 0, minor = 0] = process.versions.node.split('.').map(Number);
  check('node', major > MIN_NODE[0]! || (major === MIN_NODE[0] && minor >= MIN_NODE[1]!), process.versions.node);
  for (const key of MACHINE_KEYS) {
    // The port folder is output: made on first use, so only where it goes must exist.
    if (key === 'ports' && !fs.existsSync(m.ports)) check(key, fs.existsSync(path.dirname(m.ports)), `${m.ports} (made on first use)`);
    else check(key, fs.existsSync(m[key]), m[key]);
  }
  if (fs.existsSync(m.game)) {
    const status = git(m.game, ['status', '--porcelain']).trim();
    console.log(`info game: ${git(m.game, ['log', '-1', '--format=%h %s']).trim()}${status ? `; not committed: ${status.split(/\r?\n/).join(', ')}` : ''}`);
  }
  if (fs.existsSync(m.source)) {
    const cache = programCache(m);
    console.log(`info source cache: graph ${fs.existsSync(cache.graph) ? 'ready' : 'to build'}, Jelly ${fs.existsSync(cache.jelly) ? 'ready' : 'to run'} (${path.dirname(cache.graph)})`);
  }
  console.log(bad === 0 ? '\ndoctor OK' : `\ndoctor: ${bad} problem(s); fix ${path.join(CONVERTER, 'configs', 'roadcraft-machine.json')}`);
  return bad === 0 ? 0 : 1;
}

function extract(m: Machine, feature: string, entries: readonly string[]): number {
  if (entries.length === 0) fail('give the feature\'s entry files, relative to the 4.0 root (e.g. src/editor/poles.ts)');
  const cache = programCache(m);
  if (!fs.existsSync(cache.graph)) {
    const code = converter(m, ['graph', '--source-root', m.source, '--typescript', m.typescript, '--out', cache.graph]);
    if (code !== 0) return code;
  }
  const out = featureDir(feature);
  const analysis = fs.existsSync(cache.jelly) ? ['--analysis', cache.jelly] : ['--jelly', m.jelly];
  const code = converter(m, ['feature', '--source-root', m.source, '--typescript', m.typescript, '--postcss', m.postcss, '--graph', cache.graph,
    ...analysis, ...entries.flatMap((e) => ['--entry', e]), '--out', out]);
  if (code !== 0) return code;
  if (!fs.existsSync(cache.jelly)) fs.cpSync(path.join(out, 'jelly'), cache.jelly, { recursive: true });
  console.log(`\nfeature ${feature}: read ${path.join(out, 'feature.md')}, then the code in ${path.join(out, 'source')} and the shared ` +
    `declarations it uses in ${path.join(out, 'interface')} (boundary.json has every list)`);
  return 0;
}

function workspace(m: Machine, feature: string): number {
  if (!fs.existsSync(featureDir(feature))) console.log(`note: no extraction of ${feature} yet (node scripts/port.ts extract ${feature} <entry>...)`);
  return converter(m, ['workspace', '--game', m.game, '--feature', feature, '--port', portDir(m, feature), '--config', SANDBOX_CONFIG]);
}

function verify(m: Machine, feature: string, steps: readonly string[]): number {
  return converter(m, ['verify', '--port', portDir(m, feature), '--config', SANDBOX_CONFIG, ...steps.flatMap((s) => ['--step', s])]);
}

function audit(m: Machine, feature: string): number {
  const port = portDir(m, feature);
  const record = readWorkspace(port);
  const config = JSON.parse(fs.readFileSync(AUDIT_CONFIG, 'utf8')) as { include: string[]; compileCommands: string; rules: string; flags: string[] };
  const compileCommands = path.join(record.workspace, config.compileCommands);
  if (!fs.existsSync(compileCommands)) fail(`${compileCommands} is missing: the workspace's debug build is configured without CMAKE_EXPORT_COMPILE_COMMANDS`);
  const dir = path.join(port, 'audit');
  const graph = path.join(dir, 'cppgraph.json');
  const result = path.join(dir, 'audit.json');
  let code = converter(m, ['cppgraph', '--root', record.workspace, '--compile-commands', compileCommands, '--clangd', m.clangd,
    `--clangd-arg=--query-driver=${m.cxx}`, ...config.include.flatMap((i) => ['--include', i]), '--cache', path.join(dir, 'clangd'), '--out', graph]);
  if (code !== 0) return code;
  code = converter(m, ['audit', '--graph', graph, '--target-rules', path.join(record.workspace, config.rules), ...config.flags,
    '--out', result, '--markdown', path.join(dir, 'audit.md')]);
  if (code !== 0) return code;
  // Only the port is judged here: the findings in lines it added or changed.
  const findings = findingsInChanges((JSON.parse(fs.readFileSync(result, 'utf8')) as AuditResult).findings,
    JSON.parse(fs.readFileSync(graph, 'utf8')) as GraphIR, changedLines(record.workspace, record.base));
  const report = [`# Audit of the port ${feature}`, '', `Findings in code the port added or changed since ${record.base.slice(0, 12)}: ${findings.length}.`, '',
    ...findings.flatMap((f) => {
      const rule = RULE_BY_ID.get(f.rule);
      return [`## ${f.severity} ${f.rule}: ${f.file}:${f.line}`, '', f.message, '',
        ...(rule ? [`- Wrong: ${rule.problem}`, `- Correct: ${rule.methodology}`, `- In the game: ${rule.target}`,
          `- Sources: ${rule.sources.map((s) => `[${s.title}](${s.url})`).join('; ')}`] : []), ''];
    })].join('\n');
  fs.writeFileSync(path.join(dir, 'port-findings.md'), report, 'utf8');
  for (const f of findings) console.log(`${f.severity.padEnd(6)} ${f.rule} ${f.file}:${f.line} ${f.message}`);
  console.log(`\naudit of the port: ${findings.length} finding(s) in its code -> ${path.join(dir, 'port-findings.md')}`);
  return findings.length === 0 ? 0 : 1;
}

function pack(m: Machine, feature: string): number {
  const out = path.join(portDir(m, feature), 'package');
  removeTree(out);
  return converter(m, ['pack', '--port', portDir(m, feature), '--feature-dir', featureDir(feature), '--source-root', m.source, '--out', out]);
}

function sandbox(m: Machine, feature: string): number {
  const dir = path.join(portDir(m, feature), 'sandbox');
  removeTree(dir);
  return converter(m, ['sandbox', '--package', path.join(portDir(m, feature), 'package'), '--config', SANDBOX_CONFIG, '--dir', dir]);
}

async function answers(url: string): Promise<boolean> {
  try {
    return (await fetch(url)).ok;
  } catch {
    return false;
  }
}

/** The same question, answered at once: whether to start the server is decided under the lock. */
function answersNow(url: string): boolean {
  const probe = 'fetch(process.argv[1]).then((r) => process.exit(r.ok ? 0 : 1), () => process.exit(1))';
  return spawnSync(process.execPath, ['-e', probe, url], { stdio: 'ignore' }).status === 0;
}

function alive(pid: number): boolean {
  try {
    process.kill(pid, 0);
    return true;
  } catch (error) {
    return (error as NodeJS.ErrnoException).code === 'EPERM';
  }
}

function sleepNow(ms: number): void {
  Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, ms);
}

/** One owner at a time over the server's bookkeeping: a folder made atomically, taken over when older than LOCK_STALE_MS. */
function underLock<T>(work: () => T): T {
  fs.mkdirSync(SERVER_DIR, { recursive: true });
  const lock = path.join(SERVER_DIR, 'lock');
  const until = Date.now() + LOCK_WAIT_MS;
  for (;;) {
    try {
      fs.mkdirSync(lock);
      break;
    } catch (error) {
      if ((error as NodeJS.ErrnoException).code !== 'EEXIST') throw error;
      try {
        if (Date.now() - fs.statSync(lock).mtimeMs > LOCK_STALE_MS) fs.rmdirSync(lock);
      } catch {
        /* taken or freed meanwhile: look again */
      }
      if (Date.now() > until) fail(`the 4.0 server bookkeeping at ${lock} stayed locked for ${LOCK_WAIT_MS / 1000} s`);
      sleepNow(50);
    }
  }
  try {
    return work();
  } finally {
    fs.rmSync(lock, { recursive: true, force: true });
  }
}

const leaseFile = (pid: number): string => path.join(SERVER_DIR, 'leases', String(pid));

/** The runs using the server now; the lease of a run whose process is gone is removed. */
function liveLeases(): number[] {
  const dir = path.join(SERVER_DIR, 'leases');
  fs.mkdirSync(dir, { recursive: true });
  const live: number[] = [];
  for (const name of fs.readdirSync(dir)) {
    const pid = Number(name);
    if (Number.isInteger(pid) && alive(pid)) live.push(pid);
    else fs.rmSync(path.join(dir, name), { force: true });
  }
  return live;
}

/** The server a run started and recorded, while its process lives. */
function recordedServer(): number | null {
  try {
    const { pid } = JSON.parse(fs.readFileSync(SERVER_STATE, 'utf8')) as { pid: number };
    return alive(pid) ? pid : null;
  } catch {
    return null;
  }
}

/** Starts a process outside this process's tree (WMI makes it nobody's child): a run stopped with its whole tree must not take the shared server along. */
function startOutsideTree(exe: string, args: readonly string[], cwd: string): number {
  const literal = (s: string): string => `'${s.replace(/'/g, "''")}'`;
  const line = [exe, ...args].map((s) => `"${s}"`).join(' ');
  const script = `$r = Invoke-CimMethod -ClassName Win32_Process -MethodName Create -Arguments @{ CommandLine = ${literal(line)}; CurrentDirectory = ${literal(cwd)} }; if ($r.ReturnValue -ne 0) { exit 1 }; $r.ProcessId`;
  const run = spawnSync('powershell', ['-NoProfile', '-NonInteractive', '-Command', script], { encoding: 'utf8' });
  const pid = Number(String(run.stdout).trim());
  if (run.status !== 0 || !Number.isInteger(pid) || pid <= 0) fail(`could not start ${exe} outside this process's tree: ${String(run.stderr).trim()}`);
  return pid;
}

/** Stops the server a run started, only when no run holds a lease; a server nobody here started is never touched. */
function stopServerIfIdle(): boolean {
  if (liveLeases().length > 0) return false;
  const pid = recordedServer();
  if (pid !== null) spawnSync('taskkill', ['/PID', String(pid), '/T', '/F'], { stdio: 'ignore' });
  fs.rmSync(SERVER_STATE, { force: true });
  return true;
}

let leaseReleased = false;
function releaseServer(): void {
  if (leaseReleased) return;
  leaseReleased = true;
  underLock(() => {
    fs.rmSync(leaseFile(process.pid), { force: true });
    stopServerIfIdle();
  });
}

/** A lease on the 4.0's dev server, started when nobody has it: two runs share one server, and the last to leave stops it. */
async function leaseServer(m: Machine): Promise<void> {
  process.on('exit', releaseServer);
  for (const signal of ['SIGINT', 'SIGTERM', 'SIGHUP'] as const) process.on(signal, () => process.exit(130));
  underLock(() => {
    liveLeases();
    fs.writeFileSync(leaseFile(process.pid), '');
    if (answersNow(SOURCE_SERVER) || recordedServer() !== null) return;
    const vite = path.join(m.source, 'node_modules', 'vite', 'bin', 'vite.js');
    const pid = startOutsideTree(process.execPath, [vite, '--host', '127.0.0.1', '--port', '5300', '--strictPort'], m.source);
    fs.writeFileSync(SERVER_STATE, JSON.stringify({ pid }));
  });
  const until = Date.now() + SERVER_WAIT_MS;
  while (!(await answers(SOURCE_SERVER))) {
    if (Date.now() > until) fail(`the 4.0's dev server did not answer at ${SOURCE_SERVER} in ${SERVER_WAIT_MS / 1000} s`);
    await new Promise((r) => setTimeout(r, POLL_MS));
  }
}

// Parses `--name value` and `--name=value` flags against a declared spec. The `=` form is the only way to pass a
// value that itself starts with `--` (a browser flag). Every path the converter touches comes from these flags:
// nothing is hard-coded, because the source and target projects move.

export interface FlagSpec {
  readonly name: string;
  readonly help: string;
  readonly required?: boolean;
  readonly repeatable?: boolean;
}

export class ArgsError extends Error {}

export class Flags {
  readonly #values: Map<string, string[]>;

  constructor(values: Map<string, string[]>) {
    this.#values = values;
  }

  one(name: string): string | undefined {
    return this.#values.get(name)?.[0];
  }

  require(name: string): string {
    const value = this.one(name);
    if (value === undefined) throw new ArgsError(`missing --${name}`);
    return value;
  }

  all(name: string): readonly string[] {
    return this.#values.get(name) ?? [];
  }
}

export function parseFlags(argv: readonly string[], specs: readonly FlagSpec[]): Flags {
  const byName = new Map(specs.map((spec) => [spec.name, spec]));
  const values = new Map<string, string[]>();
  for (let i = 0; i < argv.length; i++) {
    const token = argv[i]!;
    if (!token.startsWith('--')) throw new ArgsError(`unexpected argument: ${token}`);
    const eq = token.indexOf('=');
    const name = eq > 2 ? token.slice(2, eq) : token.slice(2);
    const spec = byName.get(name);
    if (!spec) throw new ArgsError(`unknown flag: --${name}`);
    const value = eq > 2 ? token.slice(eq + 1) : argv[++i];
    if (value === undefined || (eq <= 2 && value.startsWith('--'))) {
      throw new ArgsError(`flag --${name} needs a value (write --${name}=value for a value starting with --)`);
    }
    const list = values.get(name) ?? [];
    if (list.length > 0 && !spec.repeatable) throw new ArgsError(`flag ${token} given twice`);
    list.push(value);
    values.set(name, list);
  }
  for (const spec of specs) {
    if (spec.required && !values.has(spec.name)) throw new ArgsError(`missing required flag --${spec.name}`);
  }
  return new Flags(values);
}

export function usage(command: string, specs: readonly FlagSpec[]): string {
  const lines = specs.map((spec) => {
    const marks = [spec.required ? 'required' : '', spec.repeatable ? 'repeatable' : ''].filter(Boolean).join(', ');
    return `  --${spec.name}${marks ? ` (${marks})` : ''}  ${spec.help}`;
  });
  return [`usage: converter ${command}`, ...lines].join('\n');
}

// so no operation can land in a repository by accident; the game's repository is only ever read.
import { spawnSync } from 'node:child_process';
import { MAX_CHILD_OUTPUT_BYTES } from './files.ts';

export class GitError extends Error {}

export function git(dir: string, args: readonly string[], input?: string): string {
  const result = spawnSync('git', ['-C', dir, ...args], { encoding: 'utf8', input, maxBuffer: MAX_CHILD_OUTPUT_BYTES });
  if (result.error) throw new GitError(`git ${args.join(' ')}: ${result.error.message}`);
  if (result.status !== 0) throw new GitError(`git ${args.join(' ')} in ${dir} failed (${result.status}):\n${result.stderr}`);
  return result.stdout;
}

export function revParse(dir: string, ref: string): string {
  return git(dir, ['rev-parse', '--verify', `${ref}^{commit}`]).trim();
}

/**
 * A clone that shares nothing with its source: objects copied, not hard-linked (`--no-hardlinks`), line endings as
 * stored in the repository (`core.autocrlf=false`, set before checkout), detached at `commit`.
 */
export function cloneIsolated(source: string, target: string, commit: string): void {
  const result = spawnSync('git', ['clone', '--no-hardlinks', '--no-checkout', '-c', 'core.autocrlf=false', source, target],
    { encoding: 'utf8' });
  if (result.status !== 0) throw new GitError(`git clone ${source} -> ${target} failed:\n${result.stderr}`);
  git(target, ['checkout', '--quiet', '--detach', commit]);
}

export function uncommitted(dir: string): string[] {
  return git(dir, ['status', '--porcelain']).split(/\r?\n/).filter(Boolean).map((line) => line.slice(3));
}

// Builds the graph IR of a TypeScript project: from named entries (closing over everything they use) or, with no
// entry, from every declaration in the scope directories.
import path from 'node:path';
import { performance } from 'node:perf_hooks';
import { isInside, normalizePath, relativePath } from '../common/paths.ts';
import { IR_VERSION, type GraphIR } from './ir.ts';
import { edgeRecords, externalSummary, unitRecord } from './records.ts';
import { Registry } from './registry.ts';
import { loadTypeScript, openProgram, type SourceProgram } from './typescript.ts';
import { nameOf, statementUnits } from './units.ts';
import { Walker } from './walk.ts';

export interface GraphOptions {
  readonly sourceRoot: string;
  /** Defaults to `<sourceRoot>/tsconfig.json`. */
  readonly tsconfig?: string | undefined;
  /** The `typescript` package directory; defaults to the one the source project resolves. */
  readonly typescriptDir?: string | undefined;
  /** `file` or `file:Name` / `file:Class.member`, relative to the source root. Empty: the whole scope. */
  readonly entries: readonly string[];
  /** Directories whose declarations are the project's own code (default `src`), relative to the source root. */
  readonly include: readonly string[];
  readonly exclude: readonly string[];
}

export function buildGraph(options: GraphOptions): GraphIR {
  const started = performance.now();
  const root = normalizePath(options.sourceRoot);
  const ts = loadTypeScript(root, options.typescriptDir);
  const sp = openProgram(ts, root, options.tsconfig ?? path.join(root, 'tsconfig.json'));
  const include = (options.include.length > 0 ? options.include : ['src']).map((d) => normalizePath(path.resolve(root, d)));
  const exclude = options.exclude.map((d) => normalizePath(path.resolve(root, d)));
  const inScope = (file: string): boolean => {
    const normal = normalizePath(file);
    return include.some((d) => isInside(d, normal)) && !exclude.some((d) => isInside(d, normal));
  };
  const registry = new Registry(ts, root);
  const walker = new Walker(sp, registry, inScope, options.entries.length === 0);
  if (options.entries.length > 0) {
    for (const entry of options.entries) addEntry(sp, registry, root, entry);
  } else {
    const files = sp.program.getSourceFiles().filter((sf) => inScope(sf.fileName));
    files.sort((a, b) => normalizePath(a.fileName).localeCompare(normalizePath(b.fileName)));
    for (const sf of files) for (const statement of sf.statements) for (const ref of statementUnits(ts, statement)) registry.add(ref, null, null);
  }
  for (let i = 0; i < registry.queue.length; i++) walker.walk(registry.queue[i]!);

  const units = [...registry.units.values()]
    .map((unit) => unitRecord(sp, registry, unit, relativePath(root, unit.file)))
    .sort((a, b) => a.id.localeCompare(b.id));
  const files = [...new Set([...registry.units.values()].map((unit) => unit.file))]
    .map((file) => ({ path: relativePath(root, file), lines: sp.sourceFile(file)?.getLineStarts().length ?? 0 }))
    .sort((a, b) => a.path.localeCompare(b.path));
  const lines = files.reduce((sum, file) => sum + file.lines, 0);
  const edges = edgeRecords(registry);
  return {
    version: IR_VERSION,
    sourceRoot: root,
    language: 'ts',
    config: sp.tsconfig,
    analyzer: `typescript ${ts.version}`,
    entries: [...options.entries],
    include: include.map((d) => relativePath(root, d)),
    exclude: exclude.map((d) => relativePath(root, d)),
    files,
    units,
    edges,
    moduleLoads: [...walker.moduleLoads].sort((a, b) => a.from.localeCompare(b.from) || a.specifier.localeCompare(b.specifier)),
    external: externalSummary(units),
    unresolvedModules: walker.unresolvedModules
      .map((u) => ({ from: registry.units.get(u.from)!.id, specifier: u.specifier }))
      .sort((a, b) => a.from.localeCompare(b.from) || a.specifier.localeCompare(b.specifier)),
    stats: { files: files.length, units: units.length, edges: edges.length, lines, milliseconds: Math.round(performance.now() - started) },
  };
}

function addEntry(sp: SourceProgram, registry: Registry, root: string, spec: string): void {
  const { ts } = sp;
  const colon = spec.lastIndexOf(':');
  const named = colon > 1; // `C:/...` has its only colon at index 1
  const file = normalizePath(path.resolve(root, named ? spec.slice(0, colon) : spec));
  const sf = sp.sourceFile(file);
  if (!sf) throw new Error(`entry file is not part of the program: ${file}`);
  if (!named) {
    for (const statement of sf.statements) for (const ref of statementUnits(ts, statement)) registry.add(ref, null, null);
    return;
  }
  const name = spec.slice(colon + 1);
  const candidates = sf.statements.flatMap((statement) => statementUnits(ts, statement));
  const matches = candidates.filter((ref) => {
    const unitName = nameOf(ts, ref);
    return unitName === name || (!name.includes('.') && unitName.split(',').includes(name));
  });
  if (matches.length === 0) throw new Error(`no declaration named ${name} in ${relativePath(root, file)}`);
  for (const ref of matches) {
    registry.add(ref, null, null);
    // A class as entry: the whole class, every member included.
    if (ref.head && ts.isClassLike(ref.node)) for (const member of ref.node.members) registry.add({ node: member, head: false }, null, null);
  }
}

// Syntactic facts of one unit that the audit and the conversion rules decide on: allocations inside loops, numeric
// literals (candidates for named constants or data keys), decisions, loops, awaits, integer bit operations (JS int32
// semantics the C++ must keep), methodology patterns, winnowing fingerprints and the ranges of nested units (code
// that is not this unit's own).
import type * as TS from 'typescript';
import { tokenHash, winnow } from './fingerprint.ts';
import type { AllocationSite, NumericLiteral, PatternSite, Range } from './ir.ts';
import { startsUnit, type UnitRef } from './units.ts';
import type { TypeScriptApi } from './typescript.ts';

export interface SyntaxFacts {
  readonly loopAllocations: AllocationSite[];
  readonly numericLiterals: NumericLiteral[];
  readonly stringLiterals: number;
  readonly decisions: number;
  readonly loops: number;
  readonly awaits: number;
  readonly bitOperations: number;
  readonly nondeterminism: string[];
  readonly patterns: PatternSite[];
  readonly fingerprints: [number, number][];
  readonly nested: Range[];

/** Array methods whose function argument runs once per element: its body is a loop body. */
const ITERATION_METHODS = new Set([
  'forEach', 'map', 'filter', 'reduce', 'reduceRight', 'some', 'every', 'find', 'findIndex', 'findLast',
  'findLastIndex', 'flatMap', 'sort',
]);
/** Calls that return a fresh array or string. */
const COPYING_METHODS = new Set(['slice', 'map', 'filter', 'concat', 'flat', 'flatMap', 'toSorted', 'toReversed', 'split', 'join']);
/** The naming convention of a named constant: its value is owned there, not a bare number. */
const CONSTANT_NAME = /^[A-Z][A-Z0-9_]*$/;
/** WebGL calls that stall the calling thread until the GPU answers (MDN, WebGL best practices). */
const SYNC_GPU_CALLS = new Set([
  'readPixels', 'getError', 'getBufferSubData', 'checkFramebufferStatus', 'getParameter', 'getProgramParameter',
  'getShaderParameter', 'getProgramInfoLog', 'getShaderInfoLog',
]);
/** Distance computations: inside a nested loop they are an all-pairs proximity search. */
const DISTANCE_CALL = /(^|\.)(hypot|sqrt|distanceTo|distanceToSquared|distanceSq|distance)$/;

function isLoop(ts: TypeScriptApi, n: TS.Node): boolean {
  return ts.isForStatement(n) || ts.isForOfStatement(n) || ts.isForInStatement(n) || ts.isWhileStatement(n) ||
    ts.isDoStatement(n);
}

function isIterationCallback(ts: TypeScriptApi, n: TS.Node): boolean {
  const call = n.parent;
  if (!call || !ts.isCallExpression(call) || !call.arguments.includes(n as TS.Expression)) return false;
  return ts.isPropertyAccessExpression(call.expression) && ITERATION_METHODS.has(call.expression.name.text);
}

function allocationOf(ts: TypeScriptApi, n: TS.Node): string | null {
  if (ts.isNewExpression(n)) return `new ${n.expression.getText()}`;
  if (ts.isArrayLiteralExpression(n)) return 'array literal';
  if (ts.isObjectLiteralExpression(n)) return 'object literal';
  if (ts.isArrowFunction(n) || ts.isFunctionExpression(n)) return 'closure';
  if (ts.isSpreadElement(n)) return 'spread';
  if (ts.isTemplateExpression(n)) return 'template string';
  if (ts.isCallExpression(n) && ts.isPropertyAccessExpression(n.expression) && COPYING_METHODS.has(n.expression.name.text)) {
    return `.${n.expression.name.text}()`;
  }
  if (ts.isCallExpression(n) && n.expression.getText() === 'Array.from') return 'Array.from()';
  return null;
}

function literalContext(ts: TypeScriptApi, n: TS.Node): NumericLiteral['context'] {
  const p = n.parent;
  if (p && ts.isElementAccessExpression(p) && p.argumentExpression === n) return 'index';
  if (p && ts.isEnumMember(p)) return 'enum';
  if (p && (ts.isParameter(p) || ts.isBindingElement(p)) && p.initializer === n) return 'default';
  if (p && (ts.isVariableDeclaration(p) || ts.isPropertyDeclaration(p)) && p.initializer === n && ts.isIdentifier(p.name) &&
    CONSTANT_NAME.test(p.name.text)) {
    return 'constant';
  }
  return 'value';
}

function isDecision(ts: TypeScriptApi, n: TS.Node): boolean {
  if (ts.isIfStatement(n) || ts.isConditionalExpression(n) || ts.isCaseClause(n) || ts.isCatchClause(n)) return true;
  if (ts.isBinaryExpression(n)) {
    const op = n.operatorToken.kind;
    return op === ts.SyntaxKind.AmpersandAmpersandToken || op === ts.SyntaxKind.BarBarToken ||
      op === ts.SyntaxKind.QuestionQuestionToken;
  }
  return (ts.isPropertyAccessExpression(n) || ts.isElementAccessExpression(n) || ts.isCallExpression(n)) &&
    n.questionDotToken !== undefined;
}

function isBitOperation(ts: TypeScriptApi, n: TS.Node): boolean {
  const k = ts.SyntaxKind;
  if (ts.isPrefixUnaryExpression(n)) return n.operator === k.TildeToken;
  if (!ts.isBinaryExpression(n)) return false;
  const op = n.operatorToken.kind;
  return op === k.BarToken || op === k.AmpersandToken || op === k.CaretToken || op === k.LessThanLessThanToken ||
    op === k.GreaterThanGreaterThanToken || op === k.GreaterThanGreaterThanGreaterThanToken || op === k.BarEqualsToken ||
    op === k.AmpersandEqualsToken || op === k.CaretEqualsToken || op === k.LessThanLessThanEqualsToken ||
    op === k.GreaterThanGreaterThanEqualsToken || op === k.GreaterThanGreaterThanGreaterThanEqualsToken;
}

function calledName(ts: TypeScriptApi, n: TS.CallExpression): string | null {
  return ts.isPropertyAccessExpression(n.expression) ? n.expression.name.text : ts.isIdentifier(n.expression) ? n.expression.text : null;
}

/** The nodes a unit owns: a class head owns its name and heritage only (fields and methods are units). */
function ownedRoots(ts: TypeScriptApi, ref: UnitRef): TS.Node[] {
  if (ref.head && ts.isClassLike(ref.node)) return [...(ref.node.name ? [ref.node.name] : []), ...(ref.node.heritageClauses ?? [])];
  return [ref.node];
}

export function syntaxFacts(ts: TypeScriptApi, ref: UnitRef): SyntaxFacts {
  const sf = ref.node.getSourceFile();
  const root = ref.node;
  const position = (pos: number): { line: number; column: number } => {
    const lc = sf.getLineAndCharacterOfPosition(pos);
    return { line: lc.line + 1, column: lc.character + 1 };
  };
  const line = (n: TS.Node): number => position(n.getStart(sf)).line;
  const facts = {
    loopAllocations: [] as AllocationSite[], numericLiterals: [] as NumericLiteral[], stringLiterals: 0, decisions: 0,
    loops: 0, awaits: 0, bitOperations: 0, nondeterminism: [] as string[], patterns: [] as PatternSite[], nested: [] as Range[],
  };
  const isOwnNested = (n: TS.Node): boolean => n !== root && startsUnit(ts, n);
  const containsDistance = (n: TS.Node): boolean => {
    let found = false;
    const scan = (m: TS.Node): void => {
      if (found || isOwnNested(m)) return;
      if (ts.isCallExpression(m) && DISTANCE_CALL.test(m.expression.getText())) found = true;
      else ts.forEachChild(m, scan);
    };
    ts.forEachChild(n, scan);
    return found;
  };
  const visit = (n: TS.Node, loopDepth: number): void => {
    if (isOwnNested(n)) {
      facts.nested.push({ start: position(n.getStart(sf)), end: position(n.end) });
      return;
    }
    let depth = loopDepth;
    if (isLoop(ts, n)) {
      facts.loops++;
      if (loopDepth > 0 && containsDistance(n)) facts.patterns.push({ id: 'quadratic-proximity', line: line(n), detail: 'distance computed in a nested loop' });
      depth++;
    }
    if (isIterationCallback(ts, n)) { facts.loops++; depth++; }
    if (isDecision(ts, n)) facts.decisions++;
    if (isBitOperation(ts, n)) facts.bitOperations++;
    if (ts.isAwaitExpression(n) || (ts.isForOfStatement(n) && n.awaitModifier)) facts.awaits++;
    if (ts.isStringLiteral(n) || ts.isNoSubstitutionTemplateLiteral(n)) facts.stringLiterals++;
    // Details describe the pattern, never quote the source: the audit is read by people barred from the source.
    if (ts.isDeleteExpression(n)) facts.patterns.push({ id: 'object-delete', line: line(n), detail: 'property removed with delete' });
    if ((ts.isNewExpression(n) || ts.isCallExpression(n)) && n.expression.getText() === 'Array' && n.arguments?.length === 1) {
      facts.patterns.push({ id: 'holey-array', line: line(n), detail: 'array preallocated with Array(n)' });
    }
    if (ts.isNewExpression(n) && n.expression.getText() === 'Date' && (n.arguments?.length ?? 0) === 0) facts.nondeterminism.push('es:new Date()');
    if (ts.isCallExpression(n)) {
      const name = calledName(ts, n);
      if (name === 'shift' && n.arguments.length === 0 && loopDepth > 0) facts.patterns.push({ id: 'queue-shift', line: line(n), detail: 'shift() inside a loop' });
      if (name !== null && SYNC_GPU_CALLS.has(name) && ts.isPropertyAccessExpression(n.expression)) facts.patterns.push({ id: 'sync-gpu-readback', line: line(n), detail: `${name}()` });
      if (name === 'postMessage' && n.arguments.length === 1) facts.patterns.push({ id: 'worker-copy', line: line(n), detail: 'postMessage without a transfer list' });
    }
    if (loopDepth > 0) {
      const what = allocationOf(ts, n);
      if (what) facts.loopAllocations.push({ line: line(n), what });
    }
    if (ts.isNumericLiteral(n)) {
      const negative = n.parent !== undefined && ts.isPrefixUnaryExpression(n.parent) && n.parent.operator === ts.SyntaxKind.MinusToken;
      const text = (negative ? '-' : '') + n.text;
      facts.numericLiterals.push({ text, line: line(n), context: literalContext(ts, negative ? n.parent : n) });
    }
    ts.forEachChild(n, (child) => visit(child, depth));
  };
  const hashes: number[] = [];
  const tokenLines: number[] = [];
  const tokens = (n: TS.Node): void => {
    if (isOwnNested(n) || (n.kind >= ts.SyntaxKind.FirstJSDocNode && n.kind <= ts.SyntaxKind.LastJSDocNode)) return;
    const children = n.getChildren(sf);
    if (children.length === 0) {
      if (n.kind !== ts.SyntaxKind.EndOfFileToken) {
        hashes.push(tokenHash(n.getText(sf)));
        tokenLines.push(line(n));
      }
      return;
    }
    for (const child of children) tokens(child);
  };
  for (const owned of ownedRoots(ts, ref)) {
    visit(owned, 0);
    tokens(owned);
  }
  return { ...facts, fingerprints: winnow(hashes, tokenLines) };
}

// Winnowing fingerprints (Schleimer, Wilkerson and Aiken, "Winnowing: Local Algorithms for Document
// Fingerprinting", SIGMOD 2003): hashes of every k-gram of the exact token sequence, keeping the minimum of each
// window of w consecutive hashes. Any identical run of at least w + k - 1 tokens shares a fingerprint, so k = 40 and
// w = 41 find every duplicate of 80 tokens or more: the threshold of the target project's clone gate.

export const GRAM_TOKENS = 40;
export const WINDOW_GRAMS = 41;
const BASE = 0x01000193;

export function tokenHash(text: string): number {
  let h = 0x811c9dc5;
  for (let i = 0; i < text.length; i++) h = Math.imul(h ^ text.charCodeAt(i), 0x01000193);
  return h | 0;
}

/** `hashes[i]` and `lines[i]` describe token i; returns [fingerprint, line of the k-gram's first token] pairs. */
export function winnow(hashes: readonly number[], lines: readonly number[]): [number, number][] {
  const grams: number[] = [];
  let power = 1;
  for (let i = 0; i < GRAM_TOKENS - 1; i++) power = Math.imul(power, BASE);
  let h = 0;
  for (let i = 0; i < hashes.length; i++) {
    if (i >= GRAM_TOKENS) h = (h - Math.imul(hashes[i - GRAM_TOKENS]!, power)) | 0;
    h = (Math.imul(h, BASE) + hashes[i]!) | 0;
    if (i >= GRAM_TOKENS - 1) grams.push(h >>> 0);
  }
  // Fewer than w + k - 1 tokens cannot hold a duplicate of the threshold length.
  if (grams.length < WINDOW_GRAMS) return [];
  const out: [number, number][] = [];
  let last = -1;
  for (let start = 0; start + WINDOW_GRAMS <= grams.length; start++) {
    let min = start;
    for (let j = start; j < start + WINDOW_GRAMS; j++) if (grams[j]! <= grams[min]!) min = j;
    if (min !== last) {
      out.push([grams[min]!, lines[min]!]);
      last = min;
    }
  }
  return out;
}

// Human-readable view of a graph IR: the call tree of the callable units and the code of every unit, by file.
// It is rendered from the IR (not from the AST), so what a person reads is exactly what the later stages consume.
import fs from 'node:fs';
import path from 'node:path';
import type { EdgeKind, GraphIR, UnitRecord } from './ir.ts';

const TREE_KINDS = new Set<EdgeKind>(['call', 'construct', 'implementation', 'callbackAssign', 'moduleLoad']);

function label(unit: UnitRecord): string {
  return `${unit.name} (${unit.file}:${unit.start.line})`;
}

function tree(ir: GraphIR, byId: Map<string, UnitRecord>): string[] {
  const children = new Map<string, string[]>();
  const incoming = new Set<string>();
  for (const edge of ir.edges) {
    if (!TREE_KINDS.has(edge.kind) || !byId.get(edge.to)?.facts.callable) continue;
    const list = children.get(edge.from) ?? [];
    if (!list.includes(edge.to)) list.push(edge.to);
    children.set(edge.from, list);
    incoming.add(edge.to);
  }
  const roots = ir.units.filter((u) => u.facts.callable && !incoming.has(u.id)).map((u) => u.id);
  const out: string[] = [];
  const printed = new Set<string>();
  const print = (id: string, depth: number, path: Set<string>): void => {
    const unit = byId.get(id)!;
    const repeated = printed.has(id);
    out.push(`${'  '.repeat(depth)}${label(unit)}${repeated ? '  (listed above)' : ''}`);
    if (repeated) return;
    printed.add(id);
    for (const child of children.get(id) ?? []) if (!path.has(child)) print(child, depth + 1, new Set([...path, child]));
  };
  for (const root of roots) print(root, 0, new Set([root]));
  return out;
}

function code(ir: GraphIR): string[] {
  const out: string[] = [];
  const byFile = new Map<string, UnitRecord[]>();
  for (const unit of ir.units) byFile.set(unit.file, [...(byFile.get(unit.file) ?? []), unit]);
  const firstMemberLine = new Map<string, number>();
  for (const unit of ir.units) {
    if (unit.parent !== null) firstMemberLine.set(unit.parent, Math.min(firstMemberLine.get(unit.parent) ?? Infinity, unit.start.line));
  }
  for (const [file, units] of [...byFile].sort(([a], [b]) => a.localeCompare(b))) {
    const lines = fs.readFileSync(path.join(ir.sourceRoot, file), 'utf8').split(/\r?\n/);
    out.push(`### ${file}`, '', '```' + ir.language);
    for (const unit of [...units].sort((a, b) => a.start.line - b.start.line)) {
      // A class head prints its declaration line(s) only; its members are units of their own.
      const last = unit.kind === 'class' ? Math.max(unit.start.line, (firstMemberLine.get(unit.id) ?? unit.end.line) - 1) : unit.end.line;
      out.push(`// line ${unit.start.line}`);
      for (let n = unit.start.line; n <= last; n++) {
        // Nested units are printed as units of their own (when used); here they are only marked.
        const nested = unit.nested.find((r) => n >= r.start.line && n <= r.end.line);
        if (nested) {
          if (n === nested.start.line) out.push(`  // ... nested unit at line ${n}: ${lines[n - 1]!.trim().slice(0, 60)}`);
          continue;
        }
        out.push(lines[n - 1]!);
      }
      out.push('');
    }
    out.push('```', '');
  }
  return out;
}

export function renderMarkdown(ir: GraphIR): string {
  const byId = new Map(ir.units.map((u) => [u.id, u]));
  const callables = ir.units.filter((u) => u.facts.callable).length;
  return [
    `# Graph: ${ir.entries.length > 0 ? ir.entries.join(', ') : `whole scope (${ir.include.join(', ')})`}`,
    '',
    `${ir.stats.units} units (${callables} callable) in ${ir.stats.files} files, ${ir.stats.edges} edges, ` +
      `${ir.external.length} external APIs; ${ir.stats.milliseconds} ms.`,
    '',
    '## Call tree',
    '',
    '```',
    ...tree(ir, byId),
    '```',
    '',
    '## Code by file',
    '',
    ...code(ir),
  ].join('\n');
}

// Names where an out-of-scope declaration comes from (a package, a TypeScript standard library, or project files
// outside the analysed scope), so every external API the source touches gets one stable key in the closed-world
// catalog that the rule stage must cover completely.
import type * as TS from 'typescript';
import { normalizePath, relativePath } from '../common/paths.ts';
import type { TypeScriptApi } from './typescript.ts';

const LIB_FILE = /\/lib\.([a-z0-9.]+)\.d\.ts$/i;

export function moduleOf(file: string, root: string): string {
  const normal = normalizePath(file);
  const lib = LIB_FILE.exec(normal);
  if (lib && /\/typescript\/lib\//.test(normal)) return libraryName(lib[1]!);
  const marker = normal.lastIndexOf('/node_modules/');
  if (marker >= 0) {
    const parts = normal.slice(marker + '/node_modules/'.length).split('/');
    const name = parts[0]!.startsWith('@') ? `${parts[0]}/${parts[1]}` : parts[0]!;
    // @types/foo describes foo; @types/scope__pkg describes @scope/pkg.
    if (name.startsWith('@types/')) return name.slice('@types/'.length).replace(/^([^_]+)__/, '@$1/');
    return name;
  }
  if (lib) return libraryName(lib[1]!);
  return 'project:' + relativePath(root, normal);
}

function libraryName(lib: string): string {
  const name = lib.toLowerCase();
  if (name.startsWith('dom')) return 'dom';
  if (name.startsWith('webworker')) return 'webworker';
  if (name.startsWith('scripthost')) return 'scripthost';
  return 'es';
}

/** The class, interface, enum, namespace or named type literal that declares `decl`, if any. */
export function containerName(ts: TypeScriptApi, decl: TS.Node): string | null {
  for (let node = decl.parent; node && !ts.isSourceFile(node); node = node.parent) {
    if (ts.isModuleDeclaration(node)) return ts.isIdentifier(node.name) ? node.name.text : null;
    if ((ts.isClassLike(node) || ts.isInterfaceDeclaration(node) || ts.isEnumDeclaration(node)) && node.name) {
      return node.name.text;
    }
    if (ts.isTypeLiteralNode(node)) {
      const owner = node.parent;
      if (owner && (ts.isTypeAliasDeclaration(owner) || ts.isVariableDeclaration(owner) || ts.isPropertySignature(owner))) {
        return ts.isIdentifier(owner.name) ? owner.name.text : null;
      }
    }
  }

// Turns the registry into the serialisable IR: positions, sizes, signatures, export status, facts and edges keyed by
// readable ids, sorted so the same source always gives byte-identical output.
import type * as TS from 'typescript';
import type { EdgeKind, EdgeRecord, ExternalSummary, ExternalUse, UnitRecord } from './ir.ts';
import { isMutableModuleVariable } from './references.ts';
import type { Registry, Unit } from './registry.ts';
import { syntaxFacts } from './facts.ts';
import type { SourceProgram } from './typescript.ts';

function hasModifier(sp: SourceProgram, n: TS.Node, kind: TS.SyntaxKind): boolean {
  const { ts } = sp;
  return ts.canHaveModifiers(n) && (ts.getModifiers(n) ?? []).some((m) => m.kind === kind);
}

function signatureOf(sp: SourceProgram, unit: Unit): string {
  const { ts, checker } = sp;
  const n = unit.ref.node;
  const flags = ts.TypeFormatFlags.NoTruncation;
  if (unit.ref.head && ts.isClassLike(n)) return (n.heritageClauses ?? []).map((h) => h.getText()).join(' ');
  if (ts.isFunctionLike(n)) {
    const signature = checker.getSignatureFromDeclaration(n);
    return signature ? checker.signatureToString(signature, undefined, flags) : '';
  }
  if (ts.isPropertyDeclaration(n)) return checker.typeToString(checker.getTypeAtLocation(n), undefined, flags);
  if (ts.isVariableStatement(n)) {
    return n.declarationList.declarations
      .map((d) => `${d.name.getText()}: ${checker.typeToString(checker.getTypeAtLocation(d), undefined, flags)}`)
      .join('; ');
  }
  return '';
}

function isCallable(sp: SourceProgram, unit: Unit): boolean {
  const { ts } = sp;
  const n = unit.ref.node;
  if (['function', 'method', 'constructor', 'getter', 'setter', 'staticBlock'].includes(unit.kind)) return true;
  return ts.isPropertyDeclaration(n) && n.initializer !== undefined &&
    (ts.isArrowFunction(n.initializer) || ts.isFunctionExpression(n.initializer));
}

function externalUses(registry: Registry, key: string): ExternalUse[] {
  const uses: ExternalUse[] = [];
  for (const [externalKey, kinds] of registry.external.get(key) ?? []) {
    for (const [kind, count] of kinds) uses.push({ key: externalKey, kind, count });
  }
  return uses.sort((a, b) => a.key.localeCompare(b.key) || a.kind.localeCompare(b.kind));
}

export function unitRecord(sp: SourceProgram, registry: Registry, unit: Unit, relativeFile: string): UnitRecord {
  const { ts } = sp;
  const n = unit.ref.node;
  const sf = n.getSourceFile();
  const start = sf.getLineAndCharacterOfPosition(n.getStart(sf));
  const end = sf.getLineAndCharacterOfPosition(n.end);
  const owner = unit.ref.head ? n : ts.isClassElement(n) && n.parent ? n.parent : n;
  const syntax = syntaxFacts(ts, unit.ref);
  const nondeterminism = [...new Set([...syntax.nondeterminism, ...(registry.nondeterminism.get(unit.key) ?? [])])].sort();
  return {
    id: unit.id,
    kind: unit.kind,
    name: unit.name,
    file: relativeFile,
    start: { line: start.line + 1, column: start.character + 1 },
    end: { line: end.line + 1, column: end.character + 1 },
    lines: end.line - start.line + 1,
    exported: hasModifier(sp, owner, ts.SyntaxKind.ExportKeyword),
    signature: signatureOf(sp, unit),
    parent: unit.parentKey ? registry.units.get(unit.parentKey)!.id : null,
    nested: syntax.nested,
    facts: {
      external: externalUses(registry, unit.key),
      nondeterminism,
      loopAllocations: syntax.loopAllocations,
      numericLiterals: syntax.numericLiterals,
      stringLiterals: syntax.stringLiterals,
      decisions: syntax.decisions,
      loops: syntax.loops,
      awaits: syntax.awaits,
      bitOperations: syntax.bitOperations,
      isStatic: hasModifier(sp, n, ts.SyntaxKind.StaticKeyword),
      callable: isCallable(sp, unit),
      mutableModuleState: isMutableModuleVariable(ts, n),
      patterns: syntax.patterns,
      fingerprints: syntax.fingerprints,
    },
  };
}

export function edgeRecords(registry: Registry): EdgeRecord[] {
  const edges: EdgeRecord[] = [];
  for (const [from, targets] of registry.edges) {
    for (const [to, kinds] of targets) {
      for (const [kind, count] of kinds) {
        edges.push({ from: registry.units.get(from)!.id, to: registry.units.get(to)!.id, kind: kind as EdgeKind, count });
      }
    }
  }
  return edges.sort((a, b) => a.from.localeCompare(b.from) || a.to.localeCompare(b.to) || a.kind.localeCompare(b.kind));
}

export function externalSummary(units: readonly UnitRecord[]): ExternalSummary[] {
  const byKey = new Map<string, { uses: number; units: Set<string> }>();
  for (const unit of units) {
    for (const use of unit.facts.external) {
      const entry = byKey.get(use.key) ?? { uses: 0, units: new Set<string>() };
      entry.uses += use.count;
      entry.units.add(unit.id);
      byKey.set(use.key, entry);
    }
  }
  return [...byKey]
    .map(([key, entry]) => {
      // `three:Vector3.add`, `@scope/pkg:Name`, `project:tests/x.ts:Name` (the module itself contains a colon).
      const split = key.startsWith('project:') ? key.lastIndexOf(':') : key.indexOf(':');
      return { key, module: key.slice(0, split), symbol: key.slice(split + 1), uses: entry.uses, units: entry.units.size };
    })
    .sort((a, b) => a.key.localeCompare(b.key));
}

// Classifies one use of a resolved declaration: called, constructed, state read or written, used as a type,
// inherited, or referenced as a value. Mutation through a method of a held container (push, set, sort...) counts as a
// write of the field or variable that holds the container: that is state the target must own.
import type * as TS from 'typescript';
import type { EdgeKind } from './ir.ts';
import type { TypeScriptApi } from './typescript.ts';

const MUTATING_METHODS = new Set([
  'push', 'pop', 'shift', 'unshift', 'splice', 'sort', 'reverse', 'fill', 'copyWithin',
  'set', 'add', 'delete', 'clear',
]);

/** Skips wrappers that do not change what an expression denotes: (x), x!, x as T, x satisfies T, <T>x. */
export function outer(ts: TypeScriptApi, expr: TS.Node): TS.Node {
  let e = expr;
  while (
    e.parent &&
    (ts.isParenthesizedExpression(e.parent) || ts.isNonNullExpression(e.parent) || ts.isAsExpression(e.parent) ||
      ts.isSatisfiesExpression(e.parent) || ts.isTypeAssertionExpression(e.parent))
  ) {
    e = e.parent;
  }
  return e;
}

function isAssignmentTarget(ts: TypeScriptApi, expr: TS.Node): 'plain' | 'compound' | null {
  const p = expr.parent;
  if (!p) return null;
  if (ts.isBinaryExpression(p) && p.left === expr) {
    const op = p.operatorToken.kind;
    if (op === ts.SyntaxKind.EqualsToken) return 'plain';
    if (op >= ts.SyntaxKind.FirstCompoundAssignment && op <= ts.SyntaxKind.LastCompoundAssignment) return 'compound';
  }
  if ((ts.isPrefixUnaryExpression(p) || ts.isPostfixUnaryExpression(p)) &&
    (p.operator === ts.SyntaxKind.PlusPlusToken || p.operator === ts.SyntaxKind.MinusMinusToken)) {
    return 'compound';
  }
  return null;
}

function stateAccess(ts: TypeScriptApi, expr: TS.Node): EdgeKind[] {
  const e = outer(ts, expr);
  const assigned = isAssignmentTarget(ts, e);
  if (assigned === 'plain') return ['write'];
  if (assigned === 'compound') return ['read', 'write'];
  const p = e.parent;
  if (p && ts.isDeleteExpression(p)) return ['write'];
  // field[i] = v, field[i] += v: the container held by the field is mutated.
  if (p && ts.isElementAccessExpression(p) && p.expression === e && isAssignmentTarget(ts, outer(ts, p)) !== null) {
    return ['read', 'write'];
  }
  // field.push(v), field.set(k, v): mutation through the container's own method.
  if (p && ts.isPropertyAccessExpression(p) && p.expression === e && MUTATING_METHODS.has(p.name.text)) {
    const call = outer(ts, p).parent;
    if (call && ts.isCallExpression(call) && call.expression === outer(ts, p)) return ['read', 'write'];
  }
  return ['read'];
}

export function isModuleLevelVariable(ts: TypeScriptApi, decl: TS.Declaration): boolean {
  if (!ts.isVariableDeclaration(decl)) return false;
  const statement = decl.parent?.parent;
  return statement !== undefined && ts.isVariableStatement(statement) && statement.parent !== undefined &&
    (ts.isSourceFile(statement.parent) || ts.isModuleBlock(statement.parent));
}

/** Declarations whose value is state: fields, module-level variables and members of object literals. */
function isStateDeclaration(ts: TypeScriptApi, decl: TS.Declaration): boolean {
  if (ts.isPropertyDeclaration(decl) || ts.isPropertySignature(decl) || ts.isPropertyAssignment(decl) ||
    ts.isShorthandPropertyAssignment(decl)) {
    return true;
  }
  if (ts.isParameter(decl)) return ts.getCombinedModifierFlags(decl) !== ts.ModifierFlags.None; // parameter property
  return isModuleLevelVariable(ts, decl);
}

function heritage(ts: TypeScriptApi, id: TS.Node): EdgeKind | null {
  for (let p = id.parent; p && !ts.isSourceFile(p); p = p.parent) {
    if (ts.isHeritageClause(p)) {
      const owner = p.parent;
      if (p.token === ts.SyntaxKind.ImplementsKeyword) return 'implements';
      return ts.isInterfaceDeclaration(owner) || ts.isClassLike(owner) ? 'inherit' : null;
    }
    if (ts.isBlock(p) || ts.isClassElement(p) || ts.isTypeElement(p)) return null;
  }
  return null;
}

function inTypePosition(ts: TypeScriptApi, id: TS.Node): boolean {
  for (let p = id.parent; p && !ts.isSourceFile(p); p = p.parent) {
    if (ts.isTypeNode(p) && !ts.isExpressionWithTypeArguments(p)) return true;
    if (ts.isBlock(p) || ts.isExpressionStatement(p)) return false;
  }
  return false;
}

/** `captured`: a variable or parameter of an enclosing unit (a factory's closure state) used from a nested unit. */
export function referenceKinds(
  ts: TypeScriptApi,
  id: TS.Identifier | TS.PrivateIdentifier,
  decl: TS.Declaration,
  captured = false,
): EdgeKind[] {
  const inherited = heritage(ts, id);
  if (inherited) return [inherited];
  if (inTypePosition(ts, id)) return ['typeRef'];
  const parent = id.parent;
  const isMemberName = parent !== undefined &&
    ((ts.isPropertyAccessExpression(parent) && parent.name === id) || (ts.isQualifiedName(parent) && parent.right === id));
  const expr: TS.Node = isMemberName ? parent : id;
  const user = outer(ts, expr).parent;
  if (user && ts.isCallExpression(user) && user.expression === outer(ts, expr)) return ['call'];
  if (user && ts.isNewExpression(user) && user.expression === outer(ts, expr)) return ['construct'];
  if (user && ts.isTaggedTemplateExpression(user) && user.tag === outer(ts, expr)) return ['call'];
  if (user && ts.isDecorator(user)) return ['call'];
  // Reading a getter or assigning a setter runs it.
  if (ts.isGetAccessorDeclaration(decl) || ts.isSetAccessorDeclaration(decl)) return ['call'];
  if (captured || isStateDeclaration(ts, decl)) return stateAccess(ts, expr);
  return ['reference'];
}

export function isMutableModuleVariable(ts: TypeScriptApi, statement: TS.Node): boolean {
  if (!ts.isVariableStatement(statement)) return false;
  const flags = statement.declarationList.flags;
  return (flags & ts.NodeFlags.Const) === 0 && (flags & ts.NodeFlags.Using) === 0;
}

// The set of units reached so far, the work queue, the typed edges and the external uses, with stable readable ids
// (`relative/file.ts#Class.member`, plus `@line` when two declarations share a name).
import type * as TS from 'typescript';
import { normalizePath, relativePath } from '../common/paths.ts';
import type { EdgeKind } from './ir.ts';
import { kindOf, nameOf, ownerOf, unitKey, type UnitRef } from './units.ts';
import type { TypeScriptApi } from './typescript.ts';

export interface Unit {
  readonly key: string;
  readonly id: string;
  readonly ref: UnitRef;
  readonly file: string;
  readonly name: string;
  readonly kind: ReturnType<typeof kindOf>;
  readonly parentKey: string | null;
}

export class Registry {
  readonly units = new Map<string, Unit>();
  readonly queue: string[] = [];
  /** from → to → kind → count */
  readonly edges = new Map<string, Map<string, Map<EdgeKind, number>>>();
  /** unit key → external key → kind → count */
  readonly external = new Map<string, Map<string, Map<EdgeKind, number>>>();
  readonly nondeterminism = new Map<string, Set<string>>();
  /** Parameters and fields that hold function values: what was passed in, and who calls through them. */
  readonly #slotTargets = new Map<TS.Declaration, Map<string, UnitRef>>();
  readonly #slotCallers = new Map<TS.Declaration, Set<string>>();
  readonly #ids = new Set<string>();
  readonly #ts: TypeScriptApi;
  readonly #root: string;

  constructor(ts: TypeScriptApi, root: string) {
    this.#ts = ts;
    this.#root = root;
  }

  /** Registers the unit (and its owner) if new; records the edge from `from` when given. Returns its key. */
  add(ref: UnitRef, from: string | null, kind: EdgeKind | null): string {
    const key = unitKey(ref);
    // A unit scheduling itself is the frame loop's signature, so that self edge is kept.
    if (from !== null && kind !== null && (from !== key || kind === 'schedule')) this.edge(from, key, kind);
    if (this.units.has(key)) return key;
    const owner = ownerOf(this.#ts, ref);
    const parentKey = owner ? unitKey(owner) : null;
    const file = normalizePath(ref.node.getSourceFile().fileName);
    const name = nameOf(this.#ts, ref);
    this.units.set(key, { key, id: this.#uniqueId(ref, file, name), ref, file, name, kind: kindOf(this.#ts, ref), parentKey });
    this.queue.push(key);
    if (owner) this.add(owner, null, null);
    return key;
  }

  /** Units that hold code to run: functions, methods, accessors, and fields initialised with a function. */
  isCallable(ref: UnitRef): boolean {
    const ts = this.#ts;
    if (['function', 'method', 'constructor', 'getter', 'setter'].includes(kindOf(ts, ref))) return true;
    const n = ref.node;
    return ts.isPropertyDeclaration(n) && n.initializer !== undefined &&
      (ts.isArrowFunction(n.initializer) || ts.isFunctionExpression(n.initializer));
  }

  edge(from: string, to: string, kind: EdgeKind, times = 1): void {
    bump(nested(this.edges, from, to), kind, times);
  }

  externalUse(from: string, externalKey: string, kind: EdgeKind): void {
    bump(nested(this.external, from, externalKey), kind, 1);
  }

  /** `target` was passed into or stored in `slot`: every unit calling through the slot reaches it. */
  slotTarget(slot: TS.Declaration, target: UnitRef): void {
    const targets = this.#slotTargets.get(slot) ?? new Map<string, UnitRef>();
    this.#slotTargets.set(slot, targets);
    const key = unitKey(target);
    if (targets.has(key)) return;
    targets.set(key, target);
    for (const caller of this.#slotCallers.get(slot) ?? []) this.add(target, caller, 'indirectCall');
  }

  /** `caller` calls the function held by `slot`: it reaches every function passed into the slot, now or later. */
  slotCall(slot: TS.Declaration, caller: string): void {
    const callers = this.#slotCallers.get(slot) ?? new Set<string>();
    this.#slotCallers.set(slot, callers);
    if (callers.has(caller)) return;
    callers.add(caller);
    for (const target of this.#slotTargets.get(slot)?.values() ?? []) this.add(target, caller, 'indirectCall');
  }

  markNondeterministic(from: string, what: string): void {
    const set = this.nondeterminism.get(from) ?? new Set<string>();
    set.add(what);
    this.nondeterminism.set(from, set);
  }

  #uniqueId(ref: UnitRef, file: string, name: string): string {
    const base = `${relativePath(this.#root, file)}#${name}`;
    if (!this.#ids.has(base)) {
      this.#ids.add(base);
      return base;
    }
    const sf: TS.SourceFile = ref.node.getSourceFile();
    const withLine = `${base}@${sf.getLineAndCharacterOfPosition(ref.node.getStart(sf)).line + 1}`;
    let id = withLine;
    for (let n = 2; this.#ids.has(id); n++) id = `${withLine}~${n}`;
    this.#ids.add(id);
    return id;
  }
}

function nested(map: Map<string, Map<string, Map<EdgeKind, number>>>, a: string, b: string): Map<EdgeKind, number> {
  let inner = map.get(a);
  if (!inner) map.set(a, (inner = new Map()));
  let kinds = inner.get(b);
  if (!kinds) inner.set(b, (kinds = new Map()));
  return kinds;
}

function bump(kinds: Map<EdgeKind, number>, kind: EdgeKind, times: number): void {
  kinds.set(kind, (kinds.get(kind) ?? 0) + times);
}

// Splits the source into the units the converter reasons about: each class member, each top-level function or
// statement, each interface, and a class "head" (name, heritage, fields). Code nested inside a unit belongs to it.
import type * as TS from 'typescript';
import type { UnitKind } from './ir.ts';
import type { TypeScriptApi } from './typescript.ts';

export interface UnitRef {
  readonly node: TS.Node;
  /** True for a class head: the class itself minus its methods, which are units of their own. */
  readonly head: boolean;
}

function isFunctionBody(ts: TypeScriptApi, node: TS.Node): boolean {
  const owner = node.parent;
  return ts.isBlock(node) && owner !== undefined && ts.isFunctionLike(owner) &&
    (owner as TS.FunctionLikeDeclaration).body === node;
}

function isFunctionValue(ts: TypeScriptApi, node: TS.Node | undefined): boolean {
  return node !== undefined && (ts.isArrowFunction(node) || ts.isFunctionExpression(node));
}

/**
 * A named function declared directly in another function's body, or a method of the object a function returns:
 * the factory pattern (`function createX() { function update() {} return { update } }`). Each is a unit of its own,
 * so using one inner function does not pull the whole factory; what it captures is an edge to the factory.
 */
export function isNestedUnitNode(ts: TypeScriptApi, node: TS.Node): boolean {
  const parent = node.parent;
  if (!parent) return false;
  if (ts.isFunctionDeclaration(node) && node.name !== undefined && isFunctionBody(ts, parent)) return true;
  if (ts.isVariableStatement(node) && isFunctionBody(ts, parent)) {
    return node.declarationList.declarations.every((d) => isFunctionValue(ts, d.initializer));
  }
  const returned = ts.isObjectLiteralExpression(parent) && parent.parent !== undefined && ts.isReturnStatement(parent.parent) &&
    parent.parent.parent !== undefined && isFunctionBody(ts, parent.parent.parent);
  return returned && (ts.isMethodDeclaration(node) || (ts.isPropertyAssignment(node) && isFunctionValue(ts, node.initializer)));
}

/** True when `node` is where a unit begins (a nested unit or a class member), as opposed to code inside one. */
export function startsUnit(ts: TypeScriptApi, node: TS.Node): boolean {
  return isNestedUnitNode(ts, node) || (ts.isClassElement(node) && node.parent !== undefined && ts.isClassLike(node.parent));
}

export function unitOf(ts: TypeScriptApi, node: TS.Node): UnitRef | null {
  for (let p: TS.Node | undefined = node; p && !ts.isSourceFile(p); p = p.parent) {
    const parent: TS.Node | undefined = p.parent;
    if (!parent) return null;
    if (isNestedUnitNode(ts, p)) return { node: p, head: false };
    if (ts.isClassElement(p) && ts.isClassLike(parent)) return { node: p, head: false };
    if (ts.isFunctionDeclaration(p) && (ts.isSourceFile(parent) || ts.isModuleBlock(parent))) return { node: p, head: false };
    if (ts.isTypeElement(p) && ts.isInterfaceDeclaration(parent)) return { node: parent, head: false };
    if (ts.isSourceFile(parent) || ts.isModuleBlock(parent)) {
      return ts.isClassDeclaration(p) ? { node: p, head: true } : { node: p, head: false };
    }
  }
  return null;
}

/** Identity of a unit: the node's file and start, plus whether it is a class head. */
export function unitKey(ref: UnitRef): string {
  const sf = ref.node.getSourceFile();
  return `${ref.head ? 'H' : 'N'}${sf.fileName}@${ref.node.getStart(sf)}`;
}

/** Units declared directly by a top-level statement: a class gives its head and every member. */
export function statementUnits(ts: TypeScriptApi, statement: TS.Statement): UnitRef[] {
  if (ts.isImportDeclaration(statement) || ts.isExportDeclaration(statement) || ts.isImportEqualsDeclaration(statement)) return [];
  if (ts.isClassDeclaration(statement)) {
    return [{ node: statement, head: true }, ...statement.members.map((member) => ({ node: member, head: false }))];
  }
  if (ts.isModuleDeclaration(statement) && statement.body && ts.isModuleBlock(statement.body)) {
    return statement.body.statements.flatMap((inner) => statementUnits(ts, inner));
  }
  return [{ node: statement, head: false }];
}

export function kindOf(ts: TypeScriptApi, ref: UnitRef): UnitKind {
  const n = ref.node;
  if (ref.head || ts.isClassDeclaration(n)) return 'class';
  if (ts.isMethodDeclaration(n) || ts.isPropertyAssignment(n)) return 'method';
  if (ts.isConstructorDeclaration(n)) return 'constructor';
  if (ts.isGetAccessorDeclaration(n)) return 'getter';
  if (ts.isSetAccessorDeclaration(n)) return 'setter';
  if (ts.isPropertyDeclaration(n) || ts.isIndexSignatureDeclaration(n)) return 'field';
  if (ts.isClassStaticBlockDeclaration(n)) return 'staticBlock';
  if (ts.isFunctionDeclaration(n)) return 'function';
  if (ts.isVariableStatement(n)) {
    const allFunctions = n.declarationList.declarations.every(
      (d) => d.initializer !== undefined && (ts.isArrowFunction(d.initializer) || ts.isFunctionExpression(d.initializer)),
    );
    return allFunctions ? 'function' : 'variable';
  }
  if (ts.isInterfaceDeclaration(n)) return 'interface';
  if (ts.isTypeAliasDeclaration(n)) return 'type';
  if (ts.isEnumDeclaration(n)) return 'enum';
  if (ts.isModuleDeclaration(n)) return 'namespace';
  return 'statement';
}

function className(ts: TypeScriptApi, cls: TS.ClassLikeDeclaration): string {
  if (cls.name) return cls.name.text;
  const owner = cls.parent;
  if (owner && ts.isVariableDeclaration(owner) && ts.isIdentifier(owner.name)) return owner.name.text;
  return '<anonymous class>';
}

function memberName(ts: TypeScriptApi, member: TS.ClassElement): string {
  if (ts.isConstructorDeclaration(member)) return 'constructor';
  if (ts.isClassStaticBlockDeclaration(member)) return '<static>';
  if (ts.isIndexSignatureDeclaration(member)) return '<index>';
  const name = member.name;
  if (!name) return '<member>';
  if (ts.isIdentifier(name) || ts.isPrivateIdentifier(name) || ts.isStringLiteral(name) || ts.isNumericLiteral(name)) return name.text;
  return name.getText();
}

export function nameOf(ts: TypeScriptApi, ref: UnitRef): string {
  const own = ownName(ts, ref);
  if (!ref.head && isNestedUnitNode(ts, ref.node) && ref.node.parent) {
    const enclosing = unitOf(ts, ref.node.parent);
    if (enclosing) return `${nameOf(ts, enclosing)}.${own}`;
  }
  return own;
}

function ownName(ts: TypeScriptApi, ref: UnitRef): string {
  const n = ref.node;
  if ((ts.isMethodDeclaration(n) || ts.isPropertyAssignment(n)) && n.parent && ts.isObjectLiteralExpression(n.parent)) {
    return ts.isIdentifier(n.name) || ts.isStringLiteral(n.name) ? n.name.text : n.name.getText();
  }
  if (ref.head && ts.isClassLike(n)) return className(ts, n);
  if (ts.isClassElement(n) && n.parent && ts.isClassLike(n.parent)) return `${className(ts, n.parent)}.${memberName(ts, n)}`;
  if (ts.isVariableStatement(n)) return n.declarationList.declarations.map((d) => d.name.getText()).join(',');
  if (
    (ts.isFunctionDeclaration(n) || ts.isInterfaceDeclaration(n) || ts.isTypeAliasDeclaration(n) || ts.isEnumDeclaration(n) ||
      ts.isClassDeclaration(n)) && n.name
  ) {
    return n.name.text;
  }
  if (ts.isModuleDeclaration(n)) return n.name.text;
  return `<${ts.SyntaxKind[n.kind]}>`;
}

/**
 * The unit another one cannot exist without: a member's class head (the class's fields), a nested unit's enclosing
 * function (which creates it and holds what it captures).
 */
export function ownerOf(ts: TypeScriptApi, ref: UnitRef): UnitRef | null {
  const n = ref.node;
  if (ref.head) return null;
  if (isNestedUnitNode(ts, n)) return n.parent ? unitOf(ts, n.parent) : null;
  if (!ts.isClassElement(n) || !n.parent || !ts.isClassDeclaration(n.parent)) return null;
  const cls = n.parent;
  return cls.parent && (ts.isSourceFile(cls.parent) || ts.isModuleBlock(cls.parent)) ? { node: cls, head: true } : null;
}

// and typed edges, out-of-scope ones become external uses. Interface and abstract members reach every
// implementation, function-typed fields reach every place that stores a callback in them, and workers or dynamic

    this.#registry = registry;
    this.#inScope = inScope;
    this.#wholeScope = wholeScope;

  walk(key: string): void {

      // A nested unit or class member inside this unit is a unit of its own: its code is not this unit's.
      if (n !== root && startsUnit(ts, n)) {
        if (this.#wholeScope) this.#registry.add({ node: n, head: false }, null, null);
        return;
      }

      if (ts.isCallExpression(n) && this.#isScheduler(n)) this.#inlineSchedule(key, n);
      if (this.#isWorkerConstruction(n) || (ts.isCallExpression(n) && n.expression.kind === ts.SyntaxKind.ImportKeyword)) {
        const specifier = this.#firstString(n);
        if (specifier !== null) this.#loadModule(key, root.getSourceFile().fileName, specifier, ts.isCallExpression(n) ? 'dynamicImport' : 'worker');
      }

      if (root.name) visit(root.name);
      for (const clause of root.heritageClauses ?? []) visit(clause);
      // Constructing the class runs its field initializers, static blocks and constructor.
      for (const member of root.members) {
        if (ts.isPropertyDeclaration(member) || ts.isConstructorDeclaration(member) || ts.isClassStaticBlockDeclaration(member) ||
          ts.isIndexSignatureDeclaration(member)) {
          this.#registry.add({ node: member, head: false }, null, null);
        }
      }
      return;
    }
    visit(root);
  }

  #identifier(key: string, n: TS.Identifier | TS.PrivateIdentifier): void {
    const { ts, checker } = this.#sp;

    if (n.parent && ts.isShorthandPropertyAssignment(n.parent) && n.parent.name === n) {
      symbol = checker.getShorthandAssignmentValueSymbol(n.parent) ?? symbol;
    }
    if (!symbol) return;

    if (symbol.flags & ts.SymbolFlags.Alias) {
      const aliased = checker.getAliasedSymbol(symbol);
      if (aliased.declarations && aliased.declarations.length > 0) {
        declarations = aliased.declarations;

  /** `n` is the callee of a call through a parameter or a field: the call reaches whatever was passed into it. */

  }

  /**

   * assigned to a field it flows into the field, handed to a scheduler it runs later.

  #functionValue(key: string, n: TS.Identifier | TS.PrivateIdentifier, target: UnitRef): void {

    const parent = n.parent;
    const expr = outer(ts, parent && ts.isPropertyAccessExpression(parent) && parent.name === n ? parent : n);
    const user = expr.parent;
    if (!user) return;
    if ((ts.isCallExpression(user) || ts.isNewExpression(user)) && user.expression !== expr) {
      const args: readonly TS.Expression[] = user.arguments ?? [];
      const index = args.indexOf(expr as TS.Expression);
      if (index < 0) return;
      if (ts.isCallExpression(user) && this.#isScheduler(user)) {
        this.#registry.add(target, key, 'schedule');
        return;

      if (!declaration || ts.isJSDocSignature(declaration) || !this.#inScope(declaration.getSourceFile().fileName)) return;
      const parameter = declaration.parameters[index];
      if (parameter && !parameter.dotDotDotToken) this.#registry.slotTarget(parameter, target);
      return;
    }
    if (ts.isBinaryExpression(user) && user.right === expr && user.operatorToken.kind === ts.SyntaxKind.EqualsToken &&
      ts.isPropertyAccessExpression(user.left)) {
      const field = checker.getSymbolAtLocation(user.left.name)?.declarations?.[0];
      if (field && this.#inScope(field.getSourceFile().fileName)) this.#registry.slotTarget(field, target);
    }
  }

  /** requestAnimationFrame, setTimeout or setInterval of the platform (not a project function of that name). */
  #isScheduler(call: TS.CallExpression): boolean {
    const { ts, checker } = this.#sp;
    const callee = ts.isPropertyAccessExpression(call.expression) ? call.expression.name : call.expression;
    if (!ts.isIdentifier(callee) || !/^(requestAnimationFrame|setTimeout|setInterval)$/.test(callee.text)) return false;
    const declarations = checker.getSymbolAtLocation(callee)?.declarations ?? [];
    return declarations.length > 0 && declarations.every((d) => !this.#inScope(d.getSourceFile().fileName));
  }

  /** `requestAnimationFrame(() => tick())`: the units the inline callback calls are what runs later. */
  #inlineSchedule(key: string, call: TS.CallExpression): void {
    const { ts, checker } = this.#sp;
    for (const argument of call.arguments) {
      if (!ts.isArrowFunction(argument) && !ts.isFunctionExpression(argument)) continue;
      const visit = (m: TS.Node): void => {
        if (ts.isCallExpression(m)) {
          const callee = ts.isPropertyAccessExpression(m.expression) ? m.expression.name : m.expression;
          let symbol = checker.getSymbolAtLocation(callee);
          if (symbol && symbol.flags & ts.SymbolFlags.Alias) symbol = checker.getAliasedSymbol(symbol);
          const d = symbol?.declarations?.[0];
          const target = d && this.#inScope(d.getSourceFile().fileName) ? unitOf(ts, this.#valueDeclaration(d)) : null;
          if (target && this.#registry.isCallable(target)) this.#registry.add(target, key, 'schedule');
        }
        ts.forEachChild(m, visit);
      };
      visit(argument.body);
    }
  }

  /** `{ add }` and `{ add: add }` stand for the function `add` itself, not for the object literal's member. */
  #valueDeclaration(d: TS.Declaration): TS.Declaration {
    const { ts, checker } = this.#sp;
    let symbol: TS.Symbol | undefined;
    if (ts.isShorthandPropertyAssignment(d)) symbol = checker.getShorthandAssignmentValueSymbol(d);
    else if (ts.isPropertyAssignment(d) && ts.isIdentifier(d.initializer)) symbol = checker.getSymbolAtLocation(d.initializer);
    if (symbol && symbol.flags & ts.SymbolFlags.Alias) symbol = checker.getAliasedSymbol(symbol);
    return symbol?.declarations?.[0] ?? d;
  }

  #followDynamicDispatch(key: string, d: TS.Declaration): void {
    const { ts, checker } = this.#sp;
    const isAbstract = ts.canHaveModifiers(d) && (ts.getModifiers(d) ?? []).some((m) => m.kind === ts.SyntaxKind.AbstractKeyword);
    const isFunctionField = (ts.isPropertySignature(d) || ts.isPropertyDeclaration(d)) &&
      checker.getTypeAtLocation(d).getNonNullableType().getCallSignatures().length > 0;
    if (!ts.isMethodSignature(d) && !isAbstract && !isFunctionField) return;
    const targets = this.#dispatchTargets(d, isFunctionField);
    for (const ref of targets.implementations) this.#registry.add(ref, key, 'implementation');
    for (const ref of targets.assigners) this.#registry.add(ref, key, 'callbackAssign');
  }

  #dispatchTargets(d: TS.Declaration, isFunctionField: boolean): Targets {
    const cached = this.#targets.get(d);
    if (cached) return cached;
    const { ts, service } = this.#sp;
    const targets: Targets = { implementations: [], assigners: [] };
    this.#targets.set(d, targets);
    const name = ts.getNameOfDeclaration(d);
    if (!name) return targets;
    const dsf = d.getSourceFile();
    for (const location of service.getImplementationAtPosition(dsf.fileName, name.getStart(dsf)) ?? []) {
      const ref = this.#unitAt(location.fileName, location.textSpan.start);
      if (ref) targets.implementations.push(ref);
    }
    if (isFunctionField) {
      for (const reference of service.getReferencesAtPosition(dsf.fileName, name.getStart(dsf)) ?? []) {
        if (!reference.isWriteAccess) continue;
        const ref = this.#unitAt(reference.fileName, reference.textSpan.start);
        if (ref) targets.assigners.push(ref);
      }
    }
    return targets;
  }

  #unitAt(fileName: string, position: number): UnitRef | null {
    if (!this.#inScope(fileName)) return null;
    const sf = this.#sp.sourceFile(fileName);
    if (!sf) return null;
    const { ts } = this.#sp;
    // Assigned inside the closure: the cast keeps the compiler from narrowing it to `null`.
    let found = null as TS.Node | null;
    const visit = (n: TS.Node): void => {
      if (position >= n.getStart(sf) && position < n.end) {
        found = n;
        ts.forEachChild(n, visit);
      }
    };
    ts.forEachChild(sf, visit);
    return found ? unitOf(ts, found) : null;
  }

  #external(key: string, n: TS.Identifier | TS.PrivateIdentifier, d: TS.Declaration, fallback: string): void {
    const { ts } = this.#sp;
    const module = moduleOf(d.getSourceFile().fileName, this.#sp.root);
    const externalId = externalKey(module, containerName(ts, d), declarationName(ts, d, fallback));
    for (const kind of referenceKinds(ts, n, d)) this.#registry.externalUse(key, externalId, kind);
    if (isNondeterministic(externalId)) this.#registry.markNondeterministic(key, externalId);
  }

  #unresolvedImport(key: string, bindings: readonly TS.Declaration[]): void {
    const { ts } = this.#sp;
    for (const binding of bindings) {
      let node: TS.Node | undefined = binding;
      while (node && !ts.isImportDeclaration(node)) node = node.parent;
      if (!node || !ts.isImportDeclaration(node) || !ts.isStringLiteral(node.moduleSpecifier)) continue;
      const specifier = node.moduleSpecifier.text;
      if (/\?(shared)?worker\b/.test(specifier)) {
        this.#loadModule(key, node.getSourceFile().fileName, specifier, 'workerImport');
      } else if (!this.unresolvedModules.some((u) => u.from === key && u.specifier === specifier)) {
        this.unresolvedModules.push({ from: key, specifier });
      }
    }
  }

  #isWorkerConstruction(n: TS.Node): boolean {
    const { ts } = this.#sp;
    return ts.isNewExpression(n) && /(^|\.)(Shared)?Worker$/.test(n.expression.getText());
  }

  #firstString(n: TS.Node): string | null {
    const { ts } = this.#sp;
    let found = null as string | null;
    const visit = (m: TS.Node): void => {
      if (found !== null) return;
      if (ts.isStringLiteralLike(m)) found = m.text;
      else ts.forEachChild(m, visit);
    };
    ts.forEachChild(n, visit);
    return found;
  }

  #loadModule(key: string, fromFile: string, specifier: string, how: ModuleLoad['how']): void {
    const { ts, program } = this.#sp;
    const clean = specifier.replace(/\?.*$/, '');
    let file = ts.resolveModuleName(clean, fromFile, program.getCompilerOptions(), ts.sys).resolvedModule?.resolvedFileName;
    if (!file) {
      const base = path.resolve(path.dirname(fromFile), clean);
      file = ['', '.ts', '.tsx', '.js', '.mjs'].map((ext) => base + ext).find((f) => fs.existsSync(f) && fs.statSync(f).isFile());
    }
    const from = this.#registry.units.get(key)!.id;
    const normal = file ? normalizePath(file) : null;
    if (!this.moduleLoads.some((m) => m.from === from && m.specifier === specifier)) {
      this.moduleLoads.push({ from, specifier, file: normal, how });
    }
    const sf = normal ? this.#sp.sourceFile(normal) : undefined;
    if (!sf || !this.#inScope(sf.fileName)) return;
    for (const statement of sf.statements) {
      for (const ref of statementUnits(ts, statement)) this.#registry.add(ref, key, 'moduleLoad');
    }
  }
}

// The boundary of a feature in the whole program's graph, by dominance: a declaration is the feature's own when the
// program reaches it only through the feature (take the feature out and nothing else uses it). Everything else the
// feature touches is shared: it is the interface the feature uses, not code of the feature. The places outside that
// reach into the feature are where it plugs into the program.
//
// What the program runs: the scripts its HTML pages load (Vite's `<script type="module" src>`), and, for every file
// it reaches, what runs when the file is loaded (its statements, its variables' initializers, its classes' static
// parts: importing a module runs them). Dead code reaches nothing, so it never makes a declaration shared.
import type { EdgeKind, GraphIR, UnitRecord } from '../graph/ir.ts';
import type { Holds } from './holders.ts';

export interface FeatureUse {
  /** The shared declaration used. */
  readonly unit: string;
  readonly kind: EdgeKind;
  /** The feature's declarations that use it. */
  readonly by: string[];
}

export interface FeatureBoundary {
  /** The files the feature was given by. */
  readonly entries: readonly string[];
  /** The scripts the program starts from. */
  readonly roots: readonly string[];
  /** The feature's own declarations. */
  readonly own: readonly string[];
  /** Shared declarations the feature's code uses directly: the interface it needs from the rest of the program. */
  readonly uses: readonly FeatureUse[];
  /** Declarations outside the feature that use it: where the program plugs it in. */
  readonly hooks: readonly FeatureUse[];
  /** External APIs (packages, the platform) the feature's own code uses, with how many uses. */
  readonly external: readonly { readonly key: string; readonly count: number }[];
  /** The program's fields and variables that hold the feature's values (or values made from them, to a fixpoint). */
  readonly holders: readonly string[];
  /** The program's declarations, run by it, that name the feature or a holder: the feature has a slice of each. */
  readonly sliced: readonly string[];
  /** Every declaration the program runs without the feature (not written out: what the rest of the program is). */
  readonly program: ReadonlySet<string>;
}

/**
 * What runs when a module is evaluated (ECMAScript): its statements, the initializers of its variables (one whose value
 * is a function is a unit of kind function: it only makes the function), its classes' static blocks and static fields.
 */
const runsOnLoad = (u: UnitRecord): boolean => u.kind === 'statement' || u.kind === 'staticBlock'
  || (u.kind === 'variable' && u.parent === null) || (u.kind === 'field' && u.facts.isStatic);
/** Declarations that hold a value. */
const HOLDS = new Set(['field', 'variable', 'getter']);

export function featureBoundary(ir: GraphIR, entries: readonly string[], roots: readonly string[], holds: Holds): FeatureBoundary {
  const units = new Map(ir.units.map((u) => [u.id, u]));
  const out = new Map<string, { to: string; kind: EdgeKind }[]>();
  const into = new Map<string, { from: string; kind: EdgeKind }[]>();
  for (const e of ir.edges) {
    if (!units.has(e.from) || !units.has(e.to)) continue;
    (out.get(e.from) ?? out.set(e.from, []).get(e.from)!).push({ to: e.to, kind: e.kind });
    (into.get(e.to) ?? into.set(e.to, []).get(e.to)!).push({ from: e.from, kind: e.kind });
  }
  const byFile = new Map<string, UnitRecord[]>();
  for (const u of ir.units) (byFile.get(u.file) ?? byFile.set(u.file, []).get(u.file)!).push(u);
  const known = new Set(byFile.keys());
  for (const f of [...entries, ...roots]) if (!known.has(f)) throw new Error(`${f} has no declarations in the graph (is it in its scope?)`);

  const seed = new Set(entries.flatMap((f) => byFile.get(f)!.map((u) => u.id)));

  /** Everything reached from `start`, never entering `blocked`; a reached file runs its load-time code. */
  const reach = (start: Iterable<string>, blocked: ReadonlySet<string>): Set<string> => {
    const seen = new Set<string>();
    const loaded = new Set<string>();
    const stack: string[] = [];
    const push = (id: string): void => {
      if (seen.has(id) || blocked.has(id)) return;
      seen.add(id);
      stack.push(id);
    };
    for (const id of start) push(id);
    while (stack.length > 0) {
      const id = stack.pop()!;
      const file = units.get(id)!.file;
      if (!loaded.has(file)) {
        loaded.add(file);
        for (const u of byFile.get(file)!) if (runsOnLoad(u)) push(u.id);
      }
      for (const e of out.get(id) ?? []) push(e.to);
    }
    return seen;
  };

  const rootUnits = roots.flatMap((f) => byFile.get(f)!.filter(runsOnLoad).map((u) => u.id));
  const withoutFeature = reach(rootUnits, seed);
  const fromFeature = reach(seed, new Set());
  const own = new Set([...fromFeature].filter((id) => !withoutFeature.has(id)));

  const group = (pairs: { unit: string; kind: EdgeKind; by: string }[]): FeatureUse[] => {
    const map = new Map<string, FeatureUse>();
    for (const p of pairs) {
      const key = `${p.unit}|${p.kind}`;
      const known = map.get(key);
      if (known) { if (!known.by.includes(p.by)) known.by.push(p.by); } else map.set(key, { unit: p.unit, kind: p.kind, by: [p.by] });
    }
    return [...map.values()].sort((a, b) => a.unit.localeCompare(b.unit) || a.kind.localeCompare(b.kind));
  };
  const uses = group([...own].flatMap((id) => (out.get(id) ?? []).filter((e) => !own.has(e.to)).map((e) => ({ unit: e.to, kind: e.kind, by: id }))));
  // A hook is a place the running program reaches in from: dead code that names the feature plugs nothing in.
  const hooks = group([...own].flatMap((id) => (into.get(id) ?? []).filter((e) => withoutFeature.has(e.from)).map((e) => ({ unit: id, kind: e.kind, by: e.from }))));
  // The program's state that holds the feature's values (holders.ts decides what a stored value is), to a fixpoint.
  const feature = new Set(own);
  const holders = new Set<string>();
  const namesFeature = (id: string): boolean => (out.get(id) ?? []).some((e) => feature.has(e.to));
  for (let changed = true; changed;) {
    changed = false;
    for (const id of withoutFeature) {
      if (holders.has(id) || !HOLDS.has(units.get(id)!.kind)) continue;
      // What it is made from, or what an assignment to it is made from, names the feature; holders.ts decides.
      const written = (into.get(id) ?? []).some((e) => e.kind === 'write' && namesFeature(e.from));
      if (!(namesFeature(id) || written) || !holds(units.get(id)!, feature)) continue;
      holders.add(id);
      feature.add(id);
      changed = true;
    }
  }
  const sliced = [...withoutFeature].filter((id) => namesFeature(id));
  const external = new Map<string, number>();
  for (const id of own) for (const x of units.get(id)!.facts.external) external.set(x.key, (external.get(x.key) ?? 0) + x.count);

  return {
    entries: [...entries],
    roots: [...roots],
    own: [...own].sort(),
    uses,
    hooks,
    external: [...external].map(([key, count]) => ({ key, count })).sort((a, b) => b.count - a.count || a.key.localeCompare(b.key)),
    holders: [...holders].sort(),
    sliced: sliced.sort(),
    program: withoutFeature,
  };
}

// Which functions a call runs, from Jelly's call graph (cs-au-dk/jelly: a points-to analysis of the whole program, so
// a call through an interface, a callback or a function kept in an object reaches the function the value really is).
// Jelly is run on the program's roots, or its call graph given; its locations are matched to the TypeScript program's
// nodes. Jelly parses with Babel: a call has the same range in both; a function ends where it ends in both, but its
// start differs where TypeScript counts modifiers (`export function f` starts at `export` for TypeScript, at
// `function` for Babel), so a function is matched by its end and the nearest start before Babel's.
import { spawnSync } from 'node:child_process';
import fs from 'node:fs';
import path from 'node:path';
import type * as TS from 'typescript';

/** Jelly's call graph JSON (its `typings/callgraph.d.ts`): locations are `file:line:column:line:column`, 1-based. */
export interface JellyCallGraph {
  readonly files: readonly string[];
  readonly functions: Readonly<Record<string, string>>;
  readonly calls: Readonly<Record<string, string>>;
  readonly call2fun: readonly (readonly [number, number])[];
}

/** What Jelly wrote of a program: its call graph and its points-to sets (a file), both relative to `base`. */
export interface JellyAnalysis {
  readonly callGraph: JellyCallGraph;
  readonly tokens: string;
  readonly base: string;
}

export const CALL_GRAPH_FILE = 'callgraph.json';
export const TOKENS_FILE = 'tokens.json';

/**
 * Runs Jelly (the package directory given) on the program's roots, in `base` (its paths are then relative to it), into
 * `dir`. Only calls the program writes are edges: a callback the platform or a package calls is not given that call's
 * arguments, so its parameters are what comes from outside.
 */
export function runJelly(jellyDir: string, base: string, roots: readonly string[], dir: string): JellyAnalysis {
  const main = path.join(path.resolve(jellyDir), 'lib', 'main.js');
  if (!fs.existsSync(main)) throw new Error(`no Jelly at ${jellyDir} (expected lib/main.js of the @cs-au-dk/jelly package)`);
  fs.mkdirSync(dir, { recursive: true });
  const cg = path.resolve(dir, CALL_GRAPH_FILE);
  const tokens = path.resolve(dir, TOKENS_FILE);
  const run = spawnSync(process.execPath, ['--max-old-space-size=12288', main, '-b', '.', '-j', cg, '--tokens-json', tokens, '--no-tty',
    '--no-print-progress', '--no-callgraph-native', '--no-callgraph-external', ...roots.map((r) => path.relative(base, r))],
  { cwd: base, encoding: 'utf8', maxBuffer: 256 * 1024 * 1024 });
  if (run.status !== 0 || !fs.existsSync(cg) || !fs.existsSync(tokens)) throw new Error(`Jelly failed (exit ${run.status}):\n${(run.stderr || run.stdout).slice(-4000)}`);
  return readJelly(dir, base);
}

/** What Jelly wrote in `dir` (by `runJelly`, run in `base`). */
export function readJelly(dir: string, base: string): JellyAnalysis {
  return { callGraph: JSON.parse(fs.readFileSync(path.join(dir, CALL_GRAPH_FILE), 'utf8')) as JellyCallGraph, tokens: path.join(dir, TOKENS_FILE), base };
}

export class CallTargets {
  readonly #ts: typeof TS;
  readonly #byCall = new Map<string, string[]>();
  readonly #base: string;
  readonly #program: (file: string) => TS.SourceFile | undefined;
  /** Function-like nodes of a file, by end position. */
  readonly #functions = new Map<string, Map<number, TS.SignatureDeclaration[]>>();

  /** `base`: the directory Jelly's paths are relative to; `program`: a source file of the program by absolute path. */
  constructor(ts: typeof TS, cg: JellyCallGraph, base: string, program: (file: string) => TS.SourceFile | undefined) {
    this.#ts = ts;
    this.#base = path.resolve(base);
    this.#program = program;
    // A location with its file made absolute (calls are compared ignoring case, as Windows paths are).
    const absolute = (loc: string): string => {
      const [file, ...rest] = loc.split(':');
      return `${path.resolve(this.#base, cg.files[Number(file)]!)}:${rest.join(':')}`;
    };
    for (const [call, fn] of cg.call2fun) {
      const key = absolute(cg.calls[String(call)]!).toLowerCase();
      (this.#byCall.get(key) ?? this.#byCall.set(key, []).get(key)!).push(absolute(cg.functions[String(fn)]!));
    }
  }

  /** The functions of the program a call runs (none: a call of the platform, of a package, or one Jelly saw no target of). */
  of(call: TS.CallExpression | TS.NewExpression): TS.SignatureDeclaration[] {
    const sf = call.getSourceFile();
    const at = (pos: number): string => {
      const lc = sf.getLineAndCharacterOfPosition(pos);
      return `${lc.line + 1}:${lc.character + 1}`;
    };
    const key = `${path.resolve(sf.fileName).toLowerCase()}:${at(call.getStart(sf))}:${at(call.end)}`;
    return (this.#byCall.get(key) ?? []).map((loc) => this.#function(loc)).filter((f): f is TS.SignatureDeclaration => f !== null);
  }

  #function(loc: string): TS.SignatureDeclaration | null {
    const m = /^(.*):(\d+):(\d+):(\d+):(\d+)$/.exec(loc);
    if (!m) return null;
    const sf = this.#program(m[1]!);
    if (!sf) return null;
    const pos = (line: string, column: string): number => sf.getPositionOfLineAndCharacter(Number(line) - 1, Number(column) - 1);
    const start = pos(m[2]!, m[3]!);
    const end = pos(m[4]!, m[5]!);
    let byEnd = this.#functions.get(m[1]!);
    if (!byEnd) {
      const found = new Map<number, TS.SignatureDeclaration[]>();
      const visit = (n: TS.Node): void => {
        if (this.#ts.isFunctionLike(n)) (found.get(n.end) ?? found.set(n.end, []).get(n.end)!).push(n);
        this.#ts.forEachChild(n, visit);
      };
      visit(sf);
      byEnd = found;
      this.#functions.set(m[1]!, byEnd);
    }
    // Of the functions ending there, the one starting nearest before (or at) Babel's start: the innermost that holds it.
    let best: TS.SignatureDeclaration | null = null;
    for (const f of byEnd.get(end) ?? []) if (f.getStart(sf) <= start && (!best || f.getStart(sf) > best.getStart(sf))) best = f;
    return best;
  }
}

// Whether a field, variable or getter of the program holds the feature's values: what is stored in it (its
// initializer, every assignment to it, what a getter returns) is a value of the feature. A value is the feature's when
// it is one of its declarations or holders, a member of one, what a function of the feature returns, an instance of a
// class of the feature, or made of those (an element of an array or an object, a branch of `?:`, `??`, an operand). What
// a function of the program returns is that function's value, even when it is given the feature's: it stops there.
import type * as TS from 'typescript';
import type { GraphIR, UnitRecord } from '../graph/ir.ts';
import type { UnitIndex } from './units.ts';

export type Holds = (unit: UnitRecord, feature: ReadonlySet<string>) => boolean;

export function holdsFeature(ts: typeof TS, checker: TS.TypeChecker, index: UnitIndex, ir: GraphIR): Holds {
  const writers = new Map<string, string[]>();
  for (const e of ir.edges) if (e.kind === 'write') (writers.get(e.to) ?? writers.set(e.to, []).get(e.to)!).push(e.from);
  const declaredIn = (symbol: TS.Symbol | undefined): UnitRecord[] => {
    if (!symbol) return [];
    const s = symbol.flags & ts.SymbolFlags.Alias ? checker.getAliasedSymbol(symbol) : symbol;
    return (s.declarations ?? []).map((d) => index.unitAt(d)).filter((u): u is UnitRecord => u !== null);
  };
  const symbolOf = (n: TS.Node): TS.Symbol | undefined => {
    const p = n.parent;
    if (ts.isIdentifier(n) && p && ts.isShorthandPropertyAssignment(p) && p.name === n) return checker.getShorthandAssignmentValueSymbol(p);
    return checker.getSymbolAtLocation(n);
  };

  return (unit, feature) => {
    const isFeature = (n: TS.Node): boolean => declaredIn(symbolOf(n)).some((u) => feature.has(u.id));
    /** A type the feature declares: the type itself, a member of a union, or the element of an array or map of it. */
    const ofFeatureType = (t: TS.Type, depth = 0): boolean => {
      if (t.isUnion()) return t.types.some((x) => ofFeatureType(x, depth));
      if (declaredIn(t.aliasSymbol ?? t.getSymbol()).some((u) => feature.has(u.id))) return true;
      return depth === 0 && (t.flags & ts.TypeFlags.Object) !== 0 && checker.getTypeArguments(t as TS.TypeReference).some((a) => ofFeatureType(a, 1));
    };
    const followed = new Set<TS.Node>();
    const carries = (e: TS.Expression): boolean => {
      if (ts.isParenthesizedExpression(e) || ts.isAsExpression(e) || ts.isNonNullExpression(e) || ts.isSatisfiesExpression(e)
        || ts.isTypeAssertionExpression(e) || ts.isAwaitExpression(e)) return carries(e.expression);
      if (ts.isIdentifier(e) || ts.isPropertyAccessExpression(e)) {
        // A value whose type is one the feature declares is its value (what a parameter is given comes from callers).
        if (ofFeatureType(checker.getTypeAtLocation(e))) return true;
      }
      if (ts.isIdentifier(e)) {
        if (isFeature(e)) return true;
        // A local is what it was made from.
        const d = symbolOf(e)?.valueDeclaration;
        if (d && ts.isVariableDeclaration(d) && d.initializer && !followed.has(d)) {
          followed.add(d);
          return carries(d.initializer);
        }
        return false;
      }
      if (ts.isPropertyAccessExpression(e)) return isFeature(e.name) || carries(e.expression);
      if (ts.isElementAccessExpression(e)) return carries(e.expression);
      if (ts.isCallExpression(e)) {
        const callee = ts.isPropertyAccessExpression(e.expression) ? e.expression.name : e.expression;
        if (isFeature(callee)) return true;
        // A method of a platform type (an array's, a map's) on the feature's value gives the feature's value.
        const ofProgram = declaredIn(symbolOf(callee)).length > 0;
        return !ofProgram && ts.isPropertyAccessExpression(e.expression) && carries(e.expression.expression);
      }
      if (ts.isNewExpression(e)) return isFeature(e.expression);
      if (ts.isConditionalExpression(e)) return carries(e.whenTrue) || carries(e.whenFalse);
      if (ts.isBinaryExpression(e)) return carries(e.left) || carries(e.right);
      if (ts.isPrefixUnaryExpression(e) || ts.isPostfixUnaryExpression(e)) return carries(e.operand);
      if (ts.isArrayLiteralExpression(e)) return e.elements.some((x) => carries(ts.isSpreadElement(x) ? x.expression : x));
      if (ts.isObjectLiteralExpression(e)) {
        return e.properties.some((p) => (ts.isPropertyAssignment(p) && carries(p.initializer)) || (ts.isShorthandPropertyAssignment(p) && isFeature(p.name))
          || (ts.isSpreadAssignment(p) && carries(p.expression)));
      }
      if (ts.isTemplateExpression(e)) return e.templateSpans.some((s) => carries(s.expression));
      return false;
    };
    /** An assignment anywhere in the program that stores the feature's value in this unit. */
    const assigned = (): boolean => (writers.get(unit.id) ?? []).some((w) => {
      const node = index.nodeOf(index.units.get(w)!);
      let found = false;
      const visit = (n: TS.Node): void => {
        if (found) return;
        if (ts.isBinaryExpression(n) && n.operatorToken.kind >= ts.SyntaxKind.FirstAssignment && n.operatorToken.kind <= ts.SyntaxKind.LastAssignment) {
          const target = ts.isPropertyAccessExpression(n.left) ? n.left.name : n.left;
          if (declaredIn(symbolOf(target)).some((u) => u.id === unit.id) && carries(n.right)) found = true;
        }
        ts.forEachChild(n, visit);
      };
      if (node) visit(node);
      return found;
    });
    const node = index.nodeOf(unit);
    if (!node) return false;
    if (unit.kind === 'variable' && ts.isVariableStatement(node)) {
      return node.declarationList.declarations.some((d) => d.initializer !== undefined && carries(d.initializer)) || assigned();
    }
    if (unit.kind === 'field' && ts.isPropertyDeclaration(node)) return (node.initializer !== undefined && carries(node.initializer)) || assigned();
    if (unit.kind === 'getter' && ts.isGetAccessorDeclaration(node) && node.body) {
      let found = false;
      const visit = (n: TS.Node): void => {
        if (found || (n !== node && ts.isFunctionLike(n))) return;
        if (ts.isReturnStatement(n) && n.expression && carries(n.expression)) found = true;
        ts.forEachChild(n, visit);
      };
      visit(node.body);
      return found;
    }
    return false;
  };
}

// What the source's HTML pages load: the scripts the program starts from (Vite's `<script type="module" src>`) and
// the style sheets they link. Paths are relative to the source root, which is what a leading `/` means to Vite.
import fs from 'node:fs';
import path from 'node:path';

function pages(sourceRoot: string): string[] {
  return fs.readdirSync(sourceRoot).filter((f) => f.endsWith('.html')).sort().map((f) => fs.readFileSync(path.join(sourceRoot, f), 'utf8'));
}

const rooted = (href: string): string => href.replace(/\\/g, '/').replace(/^\//, '');

/** The scripts the program starts from. */
export function htmlRoots(sourceRoot: string): string[] {
  const roots = pages(sourceRoot).flatMap((html) => [...html.matchAll(/<script\b[^>]*\btype="module"[^>]*\bsrc="([^"]+)"/g)].map((m) => rooted(m[1]!)));
  if (roots.length === 0) throw new Error(`no <script type="module" src> in the HTML pages of ${sourceRoot}: the program has no root`);
  return roots;
}

/** The style sheets the pages link. */

  return pages(sourceRoot).flatMap((html) => [...html.matchAll(/<link\b[^>]*\brel="stylesheet"[^>]*>/g)]
    .map((m) => /\bhref="([^"]+)"/.exec(m[0])?.[1]).filter((h): h is string => h !== undefined && !/^[a-z]+:/i.test(h)).map(rooted));
}

export function writeInterface(ts: typeof TS, checker: TS.TypeChecker, index: UnitIndex, b: FeatureBoundary, slices: readonly FeatureSlice[], dir: string): InterfaceOut[] {
  const own = new Set(b.own);
  const included = new Map<string, string>();
  /** The declarations written whole (a declaration inside one of them is in its text already). */
  const whole = new Set<string>();
  const queue: UnitRecord[] = [];
  const add = (u: UnitRecord | null | undefined): void => {
    if (!u || own.has(u.id) || included.has(u.id) || queue.includes(u)) return;
    queue.push(u);
  };
  /** The declaration a name in the program stands for, when it is a declaration of the file's top level or a member. */
  const follow = (ref: TS.Node): void => {
    const symbol = checker.getSymbolAtLocation(ref);
    const s = symbol && symbol.flags & ts.SymbolFlags.Alias ? checker.getAliasedSymbol(symbol) : symbol;
    for (const d of s?.declarations ?? []) {
      const u = index.unitAt(d);
      // A local of the code it stands in is in that code's text.
      if (u && !isLocalTo(ts, d)) add(u);
    }
  };
  for (const x of b.uses) add(index.units.get(x.unit));
  // A slice of shared code is the feature's code too: what its lines read is part of what the feature uses.
  for (const slice of slices) {
    const node = index.nodeOf(index.units.get(slice.unit)!);
    if (node) for (const ref of namesOnLines(ts, node, new Set(slice.lines))) follow(ref);
  }
  for (let i = 0; i < queue.length; i++) {
    const u = queue[i]!;
    const node = index.nodeOf(u);
    if (!node) throw new Error(`no node for ${u.id}: the graph and the program disagree`);
    const { text, named, all } = written(ts, u, node);
    included.set(u.id, text);
    if (all) whole.add(u.id);
    // The types the written text names and the values a whole value is written from, declared in the program.
    for (const ref of named) follow(ref);
    if (all) for (const ref of namesIn(ts, node)) follow(ref);
  }

  const byFile = new Map<string, UnitRecord[]>();
  for (const id of included.keys()) {
    const u = index.units.get(id)!;
    (byFile.get(u.file) ?? byFile.set(u.file, []).get(u.file)!).push(u);
  }
  const out: InterfaceOut[] = [];
  for (const [file, units] of [...byFile].sort(([a], [c]) => a.localeCompare(c))) {
    const kept = units.filter((u) => !(u.parent !== null && whole.has(u.parent)))
      .sort((x, y) => x.start.line - y.start.line || x.start.column - y.start.column);
    const parts = kept.map((u) => `// ${file}:${u.start.line}-${u.end.line} ${u.kind} ${u.name}\n${included.get(u.id)!}`);
    const target = path.join(dir, file);
    fs.mkdirSync(path.dirname(target), { recursive: true });
    fs.writeFileSync(target, `// What the feature uses of ${file} (shared with the program): declarations as the source writes them, bodies left out.\n\n${parts.join('\n\n')}\n`, 'utf8');
    out.push({ file, declarations: kept.length });
  }
  return out;
}

/** A declaration's text as written here, the type names in it, and whether it is written whole. */
function written(ts: typeof TS, u: UnitRecord, node: TS.Node): { text: string; named: TS.Node[]; all: boolean } {
  const sf = node.getSourceFile();
  const start = node.getStart(sf, true);
  // A function value (a declaration, a method, a variable or a property holding one): up to its body.
  const fn = functionOf(ts, node);
  const body = fn ? (fn as TS.FunctionLikeDeclaration).body : undefined;
  if (fn && body) {
    const head = sf.text.slice(start, body.getStart(sf)).trimEnd();
    const signature: TS.Node[] = [...fn.parameters, ...(fn.typeParameters ?? []), ...(fn.type ? [fn.type] : [])];
    return { text: ts.isBlock(body) ? `${head};` : `${head} …;`, named: signature.flatMap((n) => typeNames(ts, n)), all: false };
  }
  if (u.kind === 'class' && ts.isClassLike(node)) {
    // The head: up to the brace that opens the members.
    const open = sf.text.indexOf('{', (node.heritageClauses?.at(-1) ?? node.name ?? node).end);
    return { text: `${sf.text.slice(start, open).trimEnd()} { … }`, named: (node.heritageClauses ?? []).flatMap((h) => typeNames(ts, h)), all: false };
  }
  return { text: sf.text.slice(start, node.end), named: typeNames(ts, node), all: true };
}

/** The function a callable unit is: the declaration itself, or a variable's function value. */
function functionOf(ts: typeof TS, node: TS.Node): TS.SignatureDeclaration | null {
  if (ts.isFunctionLike(node)) return node;
  if (ts.isVariableStatement(node)) {
    const init = node.declarationList.declarations[0]?.initializer;
    if (init && (ts.isArrowFunction(init) || ts.isFunctionExpression(init))) return init;
  }
  if (ts.isPropertyAssignment(node) && (ts.isArrowFunction(node.initializer) || ts.isFunctionExpression(node.initializer))) return node.initializer;
  return null;
}

/** Whether a declaration sits inside a function: a local of that code, not a declaration of the program. */
function isLocalTo(ts: typeof TS, d: TS.Node): boolean {
  for (let p = d.parent; p; p = p.parent) if (ts.isFunctionLike(p)) return true;
  return false;
}

/** The identifiers a node reads: a property name after a dot or in an object literal stands for no declaration here. */
function namesIn(ts: typeof TS, node: TS.Node): TS.Identifier[] {
  const out: TS.Identifier[] = [];
  const visit = (n: TS.Node): void => {
    if (ts.isIdentifier(n)) {
      const p = n.parent;
      const named = (ts.isPropertyAccessExpression(p) && p.name === n) || (ts.isPropertyAssignment(p) && p.name === n);
      if (!named) out.push(n);
    }
    ts.forEachChild(n, visit);
  };
  visit(node);
  return out;
}

/** The identifiers a node reads on the given lines (1-based). */
function namesOnLines(ts: typeof TS, node: TS.Node, lines: ReadonlySet<number>): TS.Identifier[] {
  const sf = node.getSourceFile();
  return namesIn(ts, node).filter((id) => lines.has(sf.getLineAndCharacterOfPosition(id.getStart(sf)).line + 1));
}

/** The names of types written in a node: type references, heritage, `typeof` queries. */
function typeNames(ts: typeof TS, node: TS.Node): TS.Node[] {
  const out: TS.Node[] = [];
  const visit = (n: TS.Node): void => {
    if (ts.isTypeReferenceNode(n)) out.push(n.typeName);
    if (ts.isExpressionWithTypeArguments(n)) out.push(n.expression);
    if (ts.isTypeQueryNode(n)) out.push(n.exprName);
    ts.forEachChild(n, visit);
  };
  visit(node);
  return out;
}

// Where code looks things up by key, by the flow of values: `X[k]` where X is an object literal of the program (through
// variables, imports, the values of another object, `?:` and `??`), and a call (of whatever function it runs: the call
// graph says) of a function that looks up with its parameter (`t(key)` reads `EN[key]`), or that hands a key made from
// its parameter to one (`plural(key)` calls `t(`${key}.one`)`), to a fixpoint. The keys a lookup is given are the strings its key expression can be (a literal, a
// template or a value made in the program: values.ts). An object's entry is used when a lookup into it is
// given its key: an object nothing looks up is used by no one, whatever its keys spell.
import type * as TS from 'typescript';
import type { StringValues } from './values.ts';

export interface KeyLookup {
  /** The objects looked up. */
  readonly objects: readonly TS.ObjectLiteralExpression[];
  /** The keys, exact, and the prefixes of keys made from a string of any value. */
  readonly exact: readonly string[];
  readonly prefixes: readonly string[];
  /** Where the lookup is written. */
  readonly at: TS.Node;
}

/** How a lookup function makes the key from its parameter: what it writes before and after it. */
type Shape = readonly [before: string, after: string];

interface LookupFunction {
  readonly objects: Set<TS.ObjectLiteralExpression>;
  readonly shapes: Map<string, Shape>;
}

/** Past this many rounds the lookup functions stop growing (a recursion making ever longer keys). */
const MAX_ROUNDS = 16;

export function keyLookups(ts: typeof TS, checker: TS.TypeChecker, files: readonly TS.SourceFile[],
  targetsOf: (call: TS.CallExpression) => readonly TS.SignatureDeclaration[], values: StringValues): KeyLookup[] {
  const strip = (e: TS.Expression): TS.Expression => {
    while (ts.isParenthesizedExpression(e) || ts.isAsExpression(e) || ts.isSatisfiesExpression(e) || ts.isNonNullExpression(e) || ts.isTypeAssertionExpression(e)) e = e.expression;
    return e;
  };
  const resolved = (s: TS.Symbol | undefined): TS.Symbol | undefined => (s && s.flags & ts.SymbolFlags.Alias ? checker.getAliasedSymbol(s) : s);

  /** The object literals an expression's value is. */
  const objectsOf = (expr: TS.Expression, seen = new Set<TS.Node>()): TS.ObjectLiteralExpression[] => {
    const e = strip(expr);
    if (seen.has(e)) return [];
    seen.add(e);
    if (ts.isObjectLiteralExpression(e)) return [e];
    if (ts.isConditionalExpression(e)) return [...objectsOf(e.whenTrue, seen), ...objectsOf(e.whenFalse, seen)];
    if (ts.isBinaryExpression(e) && [ts.SyntaxKind.QuestionQuestionToken, ts.SyntaxKind.BarBarToken].includes(e.operatorToken.kind)) {
      return [...objectsOf(e.left, seen), ...objectsOf(e.right, seen)];
    }
    if (ts.isIdentifier(e)) {
      const decl = resolved(checker.getSymbolAtLocation(e))?.valueDeclaration;
      if (decl && ts.isVariableDeclaration(decl) && decl.initializer) return objectsOf(decl.initializer, seen);
      // A JSON module imported: its one statement is the object.
      if (decl && ts.isSourceFile(decl)) {
        const first = decl.statements[0];
        return first && ts.isExpressionStatement(first) ? objectsOf(first.expression, seen) : [];
      }
      return [];
    }
    if (ts.isPropertyAccessExpression(e) || ts.isElementAccessExpression(e)) {
      const name = ts.isPropertyAccessExpression(e) ? e.name.text : null;
      return objectsOf(e.expression, seen).flatMap((o) => o.properties.flatMap((p) => {
        if (!ts.isPropertyAssignment(p) && !ts.isShorthandPropertyAssignment(p)) return [];
        if (name !== null && keyText(ts, p.name) !== name) return [];
        return objectsOf(ts.isPropertyAssignment(p) ? p.initializer : p.name, seen);
      }));
    }
    return [];
  };

  /** The strings a key expression can be, by the flow of values (values.ts); a key of any value names none in particular. */
  const keysOf = (e: TS.Expression): { exact: readonly string[]; prefixes: readonly string[] } => {
    const v = values.of(e);
    return v.top ? { exact: [], prefixes: [] } : v;
  };

  /** How an argument is made from a parameter of the function it is written in: which parameter, and the shapes. */
  const shapesOf = (arg: TS.Expression, fn: TS.SignatureDeclaration): { index: number; shape: Shape }[] => {
    const e = strip(arg);
    const paramIndex = (n: TS.Expression): number => {
      if (!ts.isIdentifier(n)) return -1;
      const decl = checker.getSymbolAtLocation(n)?.valueDeclaration;
      return decl && ts.isParameter(decl) && decl.parent === fn ? fn.parameters.indexOf(decl) : -1;
    };
    if (paramIndex(e) >= 0) return [{ index: paramIndex(e), shape: ['', ''] }];
    if (ts.isConditionalExpression(e)) return [...shapesOf(e.whenTrue, fn), ...shapesOf(e.whenFalse, fn)];
    if (ts.isTemplateExpression(e)) {
      const at = e.templateSpans.findIndex((s) => paramIndex(s.expression) >= 0);
      if (at < 0 || e.templateSpans.some((s, i) => i !== at && paramIndex(s.expression) >= 0)) return [];
      // The spans other than the parameter must be literal text for the shape to be exact.
      if (e.templateSpans.some((s, i) => i !== at && !ts.isStringLiteralLike(strip(s.expression)))) return [];
      const textOf = (s: TS.TemplateSpan): string => (strip(s.expression) as TS.StringLiteral).text;
      const head = e.head.text + e.templateSpans.slice(0, at).map((s) => textOf(s) + s.literal.text).join('');
      const tail = e.templateSpans[at]!.literal.text + e.templateSpans.slice(at + 1).map((s) => textOf(s) + s.literal.text).join('');
      return [{ index: paramIndex(e.templateSpans[at]!.expression), shape: [head, tail] }];
    }
    return [];
  };

  const enclosing = (n: TS.Node): TS.SignatureDeclaration | null => {
    for (let p = n.parent; p; p = p.parent) if (ts.isFunctionLike(p)) return p;
    return null;
  };
  const accesses: TS.ElementAccessExpression[] = [];
  const calls: TS.CallExpression[] = [];
  for (const sf of files) {
    const visit = (n: TS.Node): void => {
      if (ts.isElementAccessExpression(n)) accesses.push(n);
      if (ts.isCallExpression(n)) calls.push(n);
      ts.forEachChild(n, visit);
    };
    visit(sf);
  }
  const isWrite = (n: TS.Node): boolean => {
    const p = n.parent;
    return ts.isBinaryExpression(p) && p.left === n && p.operatorToken.kind >= ts.SyntaxKind.FirstAssignment && p.operatorToken.kind <= ts.SyntaxKind.LastAssignment;
  };

  // The lookup functions: by function, each parameter that becomes a key, with the objects and the shapes.
  const functions = new Map<TS.SignatureDeclaration, Map<number, LookupFunction>>();
  const add = (fn: TS.SignatureDeclaration, index: number, objects: Iterable<TS.ObjectLiteralExpression>, shape: Shape): boolean => {
    const byParam = functions.get(fn) ?? functions.set(fn, new Map()).get(fn)!;
    const entry = byParam.get(index) ?? byParam.set(index, { objects: new Set(), shapes: new Map() }).get(index)!;
    let changed = false;
    for (const o of objects) if (!entry.objects.has(o)) { entry.objects.add(o); changed = true; }
    const key = `${shape[0]}\u0000${shape[1]}`;
    if (!entry.shapes.has(key)) { entry.shapes.set(key, shape); changed = true; }
    return changed;
  };
  const objectsAt = new Map<TS.ElementAccessExpression, TS.ObjectLiteralExpression[]>();
  for (const a of accesses) {
    if (isWrite(a)) continue;
    const objects = objectsOf(a.expression);
    if (objects.length === 0) continue;
    objectsAt.set(a, objects);
    const fn = enclosing(a);
    if (fn) for (const { index, shape } of shapesOf(a.argumentExpression, fn)) add(fn, index, objects, shape);
  }
  // What each call runs comes from the call graph (callgraph.ts): through interfaces, callbacks, objects' functions.
  const callees = new Map(calls.map((c) => [c, targetsOf(c)] as const));
  /** The lookup functions a call runs, by parameter. */
  const lookupsOf = (c: TS.CallExpression): [number, LookupFunction][] => callees.get(c)!.flatMap((f) => [...(functions.get(f) ?? [])]);
  for (let round = 0, changed = true; changed && round < MAX_ROUNDS; round++) {
    changed = false;
    for (const c of calls) {
      const fn = enclosing(c);
      if (!fn) continue;
      for (const [j, inner] of lookupsOf(c)) {
        const arg = c.arguments[j];
        if (!arg) continue;
        for (const { index, shape } of shapesOf(arg, fn)) {
          for (const s of [...inner.shapes.values()]) changed = add(fn, index, inner.objects, [s[0] + shape[0], shape[1] + s[1]]) || changed;
        }
      }
    }
  }

  // Every lookup given keys: an access with a key of its own, a call of a lookup function with one. A key made from
  // the parameter of the function it is written in is its callers' key: when every call of the function gives that
  // parameter a known value, the lookup is theirs (the calls are lookups, with the key made as the shapes say), not
  // the function's. When nothing in the program calls it, or a call gives a value of any string, the lookup is where
  // it is written, with the values the parameter can hold.
  const callers = new Map<TS.SignatureDeclaration, TS.CallExpression[]>();
  for (const [c, fns] of callees) for (const f of fns) (callers.get(f) ?? callers.set(f, []).get(f)!).push(c);
  const fromParameter = (e: TS.Expression, at: TS.Node): boolean => {
    const fn = enclosing(at);
    const shapes = fn ? shapesOf(e, fn) : [];
    const by = fn ? callers.get(fn) ?? [] : [];
    if (shapes.length === 0 || by.length === 0) return false;
    return shapes.every(({ index }) => by.every((c) => {
      const arg = c.arguments[index];
      return arg !== undefined && !values.of(arg).top;
    }));
  };
  const out: KeyLookup[] = [];
  for (const [a, objects] of objectsAt) {
    if (fromParameter(a.argumentExpression, a)) continue;
    const keys = keysOf(a.argumentExpression);
    if (keys.exact.length + keys.prefixes.length > 0) out.push({ objects, ...keys, at: a });
  }
  for (const c of calls) {
    for (const [j, entry] of lookupsOf(c)) {
      const arg = c.arguments[j];
      if (!arg || fromParameter(arg, c)) continue;
      const keys = keysOf(arg);
      const shapes = [...entry.shapes.values()];
      const exact = keys.exact.flatMap((k) => shapes.map(([b, a]) => b + k + a));
      const prefixes = keys.prefixes.flatMap((p) => shapes.map(([b]) => b + p));
      if (exact.length + prefixes.length > 0) out.push({ objects: [...entry.objects], exact, prefixes, at: c });
    }
  }
  return out;
}

/** An object member's key as written (`a`, `'a.b'`, `1`); null for a computed one. */

  if (ts.isIdentifier(name) || ts.isStringLiteralLike(name) || ts.isNumericLiteral(name) || ts.isPrivateIdentifier(name)) return name.text;
  return null;
}

    }
    m = /^\[(.*)\]$/.exec(v);
    if (m) {
      const at = location(m[1]!);
      return at && at.el !== undefined ? `node|${at.file}:${at.sl}:${at.sc}:${at.el}:${at.ec}` : null;
    }
    m = /^This\[(.*)\]$/.exec(v);
    if (m) {
      const at = location(m[1]!);
      return at && at.el !== undefined ? `This|${at.file}|${at.sl}|${at.sc}|${at.el}|${at.ec}` : null;
    }
    // A property of an object: the object is a token (`Object[...]`), the property what follows its `]`.

        if (found) return split(found);
      }
    }
    const node = this.#byKey.get(`node|${file}:${at(e.getStart(sf))}:${at(e.end)}`);
    if (node) return split(node);
    if (ts.isPropertyAccessExpression(e)) {
      const of = this.objectsOf(e.expression, checker);
      if (!of) return null;

        if (!p) continue;

    return null;
  }

  /** The objects a class's instances are (a `new` of it is where it is made): the token of the class's range. */
  instancesOf(cls: TS.ClassLikeDeclaration): string[] {
    const sf = cls.getSourceFile();
    const end = sf.getLineAndCharacterOfPosition(cls.end);
    const start = sf.getLineAndCharacterOfPosition(cls.getStart(sf));
    return (this.#objectsByEnd.get(`${norm(sf.fileName)}:${end.line + 1}:${end.character + 1}`) ?? [])
      .filter(([l, c]) => l > start.line + 1 || (l === start.line + 1 && c >= start.character + 1)).map(([, , id]) => id);
  }

  /** The token an object literal is (where it is made). */
  literalToken(o: TS.ObjectLiteralExpression): string {
    const sf = o.getSourceFile();
    const at = (pos: number): string => {
      const lc = sf.getLineAndCharacterOfPosition(pos);
      return `${lc.line + 1}:${lc.character + 1}`;
    };
    return `Object[${norm(sf.fileName)}:${at(o.getStart(sf))}:${at(o.end)}]`;
  }

  /** `this` in code: its function's (an arrow's is its enclosing function's; a field initializer's, its class's). */
  #thisOf(e: TS.Node): Objects | null {
    const ts = this.#ts;
    let fn: TS.Node | undefined = e.parent;
    while (fn && !(ts.isFunctionLike(fn) && !ts.isArrowFunction(fn)) && !ts.isClassLike(fn)) fn = fn.parent;
    return fn ? this.#thisVar(fn) : null;
  }

  /**
   * The objects `this` is in a function or a class (a class is its own constructor: `this` in its fields' initializers
   * and in a constructor Jelly does not model apart is the class's), made in the program.
   */
  thisOf(container: TS.Node): string[] {
    const found = this.#thisVar(container) ?? (this.#ts.isConstructorDeclaration(container) ? this.#thisVar(container.parent) : null);
    return found ? [...found.objects] : [];
  }

  /** A function's or a class's `This` variable, matched by its end and the nearest start. */
  #thisVar(fn: TS.Node): Objects | null {
    const sf = fn.getSourceFile();
    const end = sf.getLineAndCharacterOfPosition(fn.end);
    const start = sf.getLineAndCharacterOfPosition(fn.getStart(sf));
    const candidates = (this.#thisByEnd.get(`${norm(sf.fileName)}:${end.line + 1}:${end.character + 1}`) ?? [])
      .filter(([l, c]) => l > start.line + 1 || (l === start.line + 1 && c >= start.character + 1));
    if (candidates.length === 0) return null;
    return split(candidates.flatMap(([, , t]) => t));
  }
}

type LocationFn = (inner: string) => { file: string; sl: number; sc: number; el?: number; ec?: number } | null;

/** Objects made in the program, apart from what comes from outside. */
function split(tokens: readonly string[]): Objects {
  const objects = tokens.filter((t) => /^(Object|Array|Function|Prototype)\[/.test(t));
  return { objects: [...new Set(objects)], outside: objects.length < tokens.length };
}

function norm(p: string): string {
  return path.resolve(p).split(path.sep).join('/').toLowerCase();

function isCodeModule(ts: typeof TS, checker: TS.TypeChecker, specifier: TS.StringLiteral, sourceRoot: string): boolean {

/** Whether a name an import binds is used by the code `inFeature` accepts. */
function usesBinding(ts: typeof TS, checker: TS.TypeChecker, sf: TS.SourceFile, st: TS.ImportDeclaration, inFeature: (n: TS.Node) => boolean): boolean {

  if (nb && ts.isNamedImports(nb)) for (const el of nb.elements) names.push(el.name);

    if (used || n === st) return;
    if (ts.isIdentifier(n)) {
      const s = checker.getSymbolAtLocation(n);
      if (s && bound.has(s) && inFeature(n)) used = true;
    }
    ts.forEachChild(n, visit);
  };
  visit(sf);
  return used;
}

// The feature's code inside code it shares with the program, by forward slicing (Weiser): in every declaration the
// program runs that names the feature (its declarations, or a field or variable of the program that holds its values),
// the statements that name it, the statements that use what those give a value to (data dependence, to a fixpoint),

import type { FeatureBoundary } from './boundary.ts';
import type { UnitIndex } from './units.ts';

export interface FeatureSlice {
  /** The program's declaration the slice is cut from. */
  readonly unit: string;
  readonly file: string;
  readonly start: number;
  readonly end: number;
  /** The lines of the declaration that are the feature's, or the headers around them (1-based, ascending). */
  readonly lines: readonly number[];

export function sliceShared(ts: typeof TS, checker: TS.TypeChecker, index: UnitIndex, b: FeatureBoundary): FeatureSlice[] {
  const feature = new Set([...b.own, ...b.holders]);
  const known = new Map<TS.Symbol, boolean>();
  const isFeature = (symbol: TS.Symbol | undefined): boolean => {
    if (!symbol) return false;
    const cached = known.get(symbol);
    if (cached !== undefined) return cached;
    const resolved = symbol.flags & ts.SymbolFlags.Alias ? checker.getAliasedSymbol(symbol) : symbol;
    const result = (resolved.declarations ?? []).some((d) => {
      const u = index.unitAt(d);
      return u !== null && feature.has(u.id);
    });
    known.set(symbol, result);
    return result;
  };
  const slices: FeatureSlice[] = [];
  for (const id of b.sliced) {
    const unit = index.units.get(id)!;
    const node = index.nodeOf(unit);
    if (!node) throw new Error(`no node for ${id}: the graph and the program disagree`);
    const slice = sliceOf(ts, checker, node, unit, isFeature);
    if (slice) slices.push(slice);
  }

}

function sliceOf(ts: typeof TS, checker: TS.TypeChecker, root: TS.Node, unit: UnitRecord, isFeature: (s: TS.Symbol | undefined) => boolean): FeatureSlice | null {
  const sf = root.getSourceFile();
  const lineOf = (pos: number): number => sf.getLineAndCharacterOfPosition(pos).line + 1;
  // Nested declarations are units of their own (sliced on their own when they name the feature).
  const nested = unit.nested.map((r) => [sf.getPositionOfLineAndCharacter(r.start.line - 1, r.start.column - 1), sf.getPositionOfLineAndCharacter(r.end.line - 1, r.end.column - 1)] as const);
  const inNested = (n: TS.Node): boolean => nested.some(([s, e]) => n.getStart(sf) >= s && n.end <= e);
  const identifiers: TS.Identifier[] = [];
  const collect = (n: TS.Node): void => {
    if (n !== root && inNested(n)) return;
    if (ts.isIdentifier(n)) identifiers.push(n);
    ts.forEachChild(n, collect);
  };
  collect(root);

  /** The statement code belongs to: the nearest node that is an element of a statement list, of a class or of an object. */
  const statementOf = (n: TS.Node): TS.Node => {
    let at = n;
    while (at !== root && at.parent) {
      const p = at.parent;
      if (p === root || ts.isBlock(p) || ts.isCaseClause(p) || ts.isDefaultClause(p) || ts.isSourceFile(p) || ts.isModuleBlock(p)
        || ts.isClassLike(p) || ts.isObjectLiteralExpression(p)) return at;
      at = p;
    }
    return at;
  };
  const symbolOf = (id: TS.Identifier): TS.Symbol | undefined => {
    const p = id.parent;
    if (p && ts.isShorthandPropertyAssignment(p) && p.name === id) return checker.getShorthandAssignmentValueSymbol(p);
    return checker.getSymbolAtLocation(id);
  };
  const isLocal = (s: TS.Symbol): boolean => (s.declarations ?? []).some((d) => d.getSourceFile() === sf && d.getStart(sf) >= root.getStart(sf) && d.end <= root.end);
  /** The locals a statement gives a value to: what it declares (variables, parameters, bindings) or assigns. */
  const defines = (st: TS.Node): TS.Symbol[] => {
    const out: TS.Symbol[] = [];
    const bind = (b: TS.BindingName): void => {
      if (ts.isIdentifier(b)) {
        const s = checker.getSymbolAtLocation(b);
        if (s) out.push(s);
      } else for (const el of b.elements) if (!ts.isOmittedExpression(el)) bind(el.name);
    };
    const visit = (n: TS.Node): void => {
      if (ts.isVariableDeclaration(n) || ts.isParameter(n)) bind(n.name);
      if (ts.isBinaryExpression(n) && n.operatorToken.kind >= ts.SyntaxKind.FirstAssignment && n.operatorToken.kind <= ts.SyntaxKind.LastAssignment && ts.isIdentifier(n.left)) {
        const s = checker.getSymbolAtLocation(n.left);
        if (s) out.push(s);
      }
      ts.forEachChild(n, visit);
    };
    visit(st);
    return out.filter(isLocal);
  };

  const kept = new Set<TS.Node>();
  const tainted = new Set<TS.Symbol>();
  const keep = (st: TS.Node): boolean => {
    if (kept.has(st)) return false;
    kept.add(st);
    for (const s of defines(st)) tainted.add(s);
    return true;
  };
  const symbols = identifiers.map(symbolOf);
  identifiers.forEach((id, i) => { if (isFeature(symbols[i])) keep(statementOf(id)); });
  if (kept.size === 0) return null;
  // Only a read carries a value on: a name being declared, or given a value by `=`, reads nothing.
  const defined = (id: TS.Identifier): boolean => {
    const p = id.parent;
    return ((ts.isVariableDeclaration(p) || ts.isParameter(p) || ts.isBindingElement(p)) && p.name === id)
      || (ts.isBinaryExpression(p) && p.operatorToken.kind === ts.SyntaxKind.EqualsToken && p.left === id);
  };
  for (let changed = true; changed;) {
    changed = false;
    identifiers.forEach((id, i) => {
      const s = symbols[i];
      if (s && tainted.has(s) && !defined(id) && keep(statementOf(id))) changed = true;
    });
  }

  const lines = new Set<number>([lineOf(root.getStart(sf)), lineOf(root.end)]);
  for (const st of kept) {
    for (let l = lineOf(st.getStart(sf)); l <= lineOf(st.end); l++) lines.add(l);
    for (let p = st.parent; p && p !== root; p = p.parent) {
      lines.add(lineOf(p.getStart(sf)));
      lines.add(lineOf(p.end));
    }
  }
  return { unit: unit.id, file: unit.file, start: unit.start.line, end: unit.end.line, lines: [...lines].sort((a, c) => a - c) };
}

// a file it shares with the program: its own declarations, each headed by its line range, and its slices of shared

export interface SourceOut {
  readonly file: string;
  /** whole: the file as it is; part: the feature's declarations and slices of it; resource: a file it imports. */
  readonly how: 'whole' | 'part' | 'resource';
  /** The lines of the file that are the feature's. */
  readonly lines: number;

export function writeSources(ir: GraphIR, b: FeatureBoundary, slices: readonly FeatureSlice[], resources: readonly FeatureResource[],
  sourceRoot: string, dir: string): SourceOut[] {
  const own = new Set(b.own);
  const byFile = new Map<string, UnitRecord[]>();
  for (const u of ir.units) (byFile.get(u.file) ?? byFile.set(u.file, []).get(u.file)!).push(u);
  const slicesOf = new Map<string, FeatureSlice[]>();
  for (const s of slices) (slicesOf.get(s.file) ?? slicesOf.set(s.file, []).get(s.file)!).push(s);
  const write = (file: string, text: string): void => {
    const target = path.join(dir, file);
    fs.mkdirSync(path.dirname(target), { recursive: true });
    fs.writeFileSync(target, text, 'utf8');
  };
  const result: SourceOut[] = [];
  for (const [file, units] of [...byFile].sort(([a], [c]) => a.localeCompare(c))) {
    const mine = units.filter((u) => own.has(u.id));
    const cut = slicesOf.get(file) ?? [];
    if (mine.length === 0 && cut.length === 0) continue;
    const text = fs.readFileSync(path.join(sourceRoot, file), 'utf8');
    if (mine.length === units.length) {
      write(file, text);
      result.push({ file, how: 'whole', lines: text.split('\n').length });
      continue;
    }
    const lines = text.split('\n');
    // A declaration inside another own one is written with it.
    const top = mine.filter((u) => !(u.parent !== null && own.has(u.parent)));
    const parts = [
      ...top.map((u) => ({ at: u.start.line, text: `// ${file}:${u.start.line}-${u.end.line} ${u.kind} ${u.name}: the feature's own\n${lines.slice(u.start.line - 1, u.end.line).join('\n')}` })),
      ...cut.map((s) => ({ at: s.start, text: renderSlice(s, lines) })),
    ].sort((x, y) => x.at - y.at);
    write(file, `// The code of ${file} that is the feature's (the rest of the file is shared).\n\n${parts.map((p) => p.text).join('\n\n')}\n`);
    result.push({ file, how: 'part', lines: top.reduce((n, u) => n + u.lines, 0) + cut.reduce((n, s) => n + s.lines.length, 0) });
  }
  // Files the feature imports that are not code, when they are the project's own files.
  for (const r of resources.filter((x) => x.kind === 'import' && x.key.startsWith('.'))) {
    const file = path.posix.normalize(path.posix.join(path.posix.dirname(r.file), r.key.replace(/\?.*$/, '')));
    const full = path.join(sourceRoot, file);
    if (!fs.existsSync(full) || result.some((s) => s.file === file)) continue;

    result.push({ file, how: 'resource', lines: text.split('\n').length });
  }

}

/** A slice as the code it was cut from: its lines, and a `…` line with the count where code is left out. */
function renderSlice(s: FeatureSlice, lines: readonly string[]): string {
  const out = [`// ${s.file}:${s.start}-${s.end} slice of ${s.unit} (shared): the feature's statements; "…" marks code left out`];
  let previous = s.start - 1;
  for (const l of s.lines) {
    if (l > previous + 1) out.push(`${/^\s*/.exec(lines[l - 1] ?? '')![0]}// … ${l - previous - 1} lines`);
    out.push(lines[l - 1] ?? '');
    previous = l;
  }
  return out.join('\n');
}

// Where code is in the graph: the units of each file, the innermost unit holding a position, and the node a unit was
// recorded from. One owner for every question of the feature stages that goes from source positions to units.
import path from 'node:path';
import type * as TS from 'typescript';
import type { GraphIR, UnitRecord } from '../graph/ir.ts';
import type { SourceProgram } from '../graph/typescript.ts';

export class UnitIndex {
  readonly units: ReadonlyMap<string, UnitRecord>;
  readonly byFile: ReadonlyMap<string, readonly UnitRecord[]>;
  readonly #sp: SourceProgram;
  readonly #nodes = new Map<string, Map<string, TS.Node>>();

  constructor(sp: SourceProgram, ir: GraphIR) {
    this.#sp = sp;
    this.units = new Map(ir.units.map((u) => [u.id, u]));
    const byFile = new Map<string, UnitRecord[]>();
    for (const u of ir.units) (byFile.get(u.file) ?? byFile.set(u.file, []).get(u.file)!).push(u);
    this.byFile = byFile;
  }

  /** A source file's path as the graph names it (relative to the source root). */
  relative(sf: TS.SourceFile): string {
    return path.relative(this.#sp.root, sf.fileName).split(path.sep).join('/');
  }

  sourceFile(file: string): TS.SourceFile | undefined {
    return this.#sp.sourceFile(path.join(this.#sp.root, file));
  }

  /** The smallest unit whose range holds a node's start. */
  unitAt(node: TS.Node): UnitRecord | null {
    const sf = node.getSourceFile();
    const at = sf.getLineAndCharacterOfPosition(node.getStart(sf));
    const line = at.line + 1;
    const column = at.character + 1;
    let best: UnitRecord | null = null;
    for (const u of this.byFile.get(this.relative(sf)) ?? []) {
      const inside = (line > u.start.line || (line === u.start.line && column >= u.start.column))
        && (line < u.end.line || (line === u.end.line && column <= u.end.column));
      if (inside && (!best || u.lines < best.lines || (u.lines === best.lines && u.start.column >= best.start.column))) best = u;
    }
    return best;
  }

  /** The node a unit was recorded from: the one that starts and ends where the unit does. */
  nodeOf(unit: UnitRecord): TS.Node | null {
    const sf = this.sourceFile(unit.file);
    if (!sf) return null;
    let nodes = this.#nodes.get(unit.file);
    if (!nodes) {
      // Each file is walked once: every node by where it starts and ends (the outermost, as a unit is recorded).
      const ts = this.#sp.ts;
      const found = new Map<string, TS.Node>();
      const visit = (n: TS.Node): void => {
        const key = `${n.getStart(sf)}:${n.end}`;
        if (!found.has(key)) found.set(key, n);
        ts.forEachChild(n, visit);
      };
      visit(sf);
      nodes = found;
      this.#nodes.set(unit.file, nodes);
    }
    const start = sf.getPositionOfLineAndCharacter(unit.start.line - 1, unit.start.column - 1);
    const end = sf.getPositionOfLineAndCharacter(unit.end.line - 1, unit.end.column - 1);
    return nodes.get(`${start}:${end}`) ?? null;
  }
}

// The strings a value can be, by the flow of values through the whole program (string constant propagation,
// flow-insensitive, solved as a worklist fixpoint). A literal is itself; a variable, a parameter, a function's result
// is what flows into it (initializers, assignments, the arguments of every call that runs the function, its returns:
// the call graph says which calls run which function). A property is per object (pointsto.ts: Jelly's points-to sets):
// `o.p` reads the property p of each object o can be, written by object literals (and what they spread), assignments,
// class fields and parameter properties. A write whose key and value are the parameters of the function it is in
// (`this.values[key] = value` in a setter) is made at each call of that function with that call's key and value (a
// write merged over every call would give each key every call's value). Templates and `+` are the combinations of
// their parts; `?:`, `??`, `||` either side. What comes from outside is any string: a variable or parameter nothing
// in the program writes (a fact raised after the propagation, which then goes on from it), an object the analysis
// could not follow, a property of the platform's, a write with a key of any value (to every property of its objects).
// A property of an object made in the program that nothing writes does not exist: it holds no string. Where an
// expression's type is a finite union of literals, the type bounds it too: both are sound, their meet is kept.
import type * as TS from 'typescript';
import type { CallTargets } from './callgraph.ts';
import type { PointsTo } from './pointsto.ts';

/** Past this many combinations a template or a `+` is read as the prefixes it starts with. */
const MAX_COMBINATIONS = 256;
/** Past this many values (a loop building ever longer strings) a storage holds any string. */
const MAX_VALUES = 4096;
/** A flow running this often has stopped being monotone: an error of the analysis, reported. */
const MAX_RUNS = 1_000_000;
/** The property of an object a write with a key of any value goes to (every property reads it too). */
const ANY_KEY = '\u0000any';

/** The strings a value can be: exact ones, the prefixes of ones made with a part of any value, or any string. */
export interface Strings {
  readonly top: boolean;
  readonly exact: readonly string[];
  readonly prefixes: readonly string[];
}

class Value {
  top = false;
  readonly exact = new Set<string>();
  readonly prefixes = new Set<string>();

  static of(...xs: string[]): Value {
    const v = new Value();
    for (const x of xs) v.exact.add(x);
    return v;
  }

  static any(): Value {
    const v = new Value();
    v.top = true;
    return v;
  }

  /** Joins another value in; true when this one grew. */
  join(o: Value): boolean {
    if (this.top) return false;
    if (o.top) {
      this.top = true;
      this.exact.clear();
      this.prefixes.clear();
      return true;
    }
    let changed = false;
    for (const x of o.exact) if (!this.exact.has(x)) { this.exact.add(x); changed = true; }
    for (const p of o.prefixes) if (!this.prefixes.has(p)) { this.prefixes.add(p); changed = true; }
    // A prefix that is empty is any string.
    if (this.prefixes.has('') || this.exact.size + this.prefixes.size > MAX_VALUES) {
      this.top = true;
      this.exact.clear();
      this.prefixes.clear();
    }
    return changed;
  }
}

export class StringValues {
  readonly #ts: typeof TS;
  readonly #checker: TS.TypeChecker;
  readonly #calls: CallTargets;
  readonly #pts: PointsTo;
  readonly #slots = new Map<TS.Node | string, Value>();
  /** Object storage (`token|property`): not raised when nothing writes it (such a property does not exist). */
  readonly #heap = new Set<Value>();
  /** What an object literal spreads in, by its token: its properties are theirs too. */
  readonly #spreads = new Map<string, TS.Expression[]>();
  readonly #callers = new Map<TS.SignatureDeclaration, (TS.CallExpression | TS.NewExpression)[]>();
  readonly #flows: { readonly apply: () => void; readonly at: TS.Node }[] = [];
  /** Where a storage first became any string (a flow's place, or nothing in the program writing it). */
  readonly #anyCause = new Map<Value, string>();
  #at: TS.Node | null = null;
  readonly #readers = new Map<Value, Set<number>>();
  readonly #written = new Set<Value>();
  readonly #read = new Set<Value>();
  readonly #queue: number[] = [];
  readonly #queued = new Set<number>();
  #current = -1;

  constructor(ts: typeof TS, checker: TS.TypeChecker, files: readonly TS.SourceFile[], calls: CallTargets, pts: PointsTo) {
    this.#ts = ts;
    this.#checker = checker;
    this.#calls = calls;
    this.#pts = pts;
    // Who calls each function: a write made per call needs them before the flows are gathered.
    for (const sf of files) {
      const visit = (n: TS.Node): void => {
        if (ts.isCallExpression(n) || ts.isNewExpression(n)) for (const f of calls.of(n)) (this.#callers.get(f) ?? this.#callers.set(f, []).get(f)!).push(n);
        ts.forEachChild(n, visit);
      };
      visit(sf);
    }
    for (const sf of files) this.#gather(sf);

  /** The strings an expression can be, from the solved flow. */
  of(e: TS.Expression): Strings {
    const v = this.#valueOf(e);
    return { top: v.top, exact: [...v.exact].sort(), prefixes: [...v.prefixes].sort() };
  }

  /** Why an expression can be any string: where any string first flowed into what it reads (null when it cannot be). */
  whyAny(e: TS.Expression): string[] {
    const out: string[] = [];
    for (const s of this.#sources(e)) if (s.top) out.push(this.#anyCause.get(s) ?? 'unknown');

  // ---- storage

  #slot(key: TS.Node | string): Value {
    let s = this.#slots.get(key);
    if (!s) this.#slots.set(key, (s = new Value()));
    return s;
  }

  #heapSlot(token: string, property: string): Value {
    const s = this.#slot(`${token}|${property}`);
    this.#heap.add(s);
    return s;
  }

  #readSlot(s: Value): Value {
    if (this.#current >= 0) {
      if (!this.#heap.has(s)) this.#read.add(s);
      (this.#readers.get(s) ?? this.#readers.set(s, new Set()).get(s)!).add(this.#current);
    } else if (!this.#written.has(s) && !this.#heap.has(s)) {
      // Asked after the fixpoint, of a storage nothing in the program writes: it holds what comes from outside.
      return Value.any();
    }
    return s;
  }

  #write(s: Value, v: Value): void {
    this.#written.add(s);
    const wasAny = s.top;
    if (!s.join(v)) return;
    if (s.top && !wasAny) this.#anyCause.set(s, this.#current >= 0 ? place(this.#flows[this.#current]!.at) : 'nothing in the program writes it');
    for (const r of this.#readers.get(s) ?? []) {
      if (this.#queued.has(r)) continue;
      this.#queued.add(r);
      this.#queue.push(r);
    }
  }

  #flow(apply: () => void): void {
    this.#flows.push({ apply, at: this.#at! });
  }

  #solve(): void {
    for (let i = 0; i < this.#flows.length; i++) { this.#queue.push(i); this.#queued.add(i); }
    const runs = new Map<number, number>();
    for (;;) {
      for (let head = 0; head < this.#queue.length; head++) {
        const f = this.#queue[head]!;
        this.#queued.delete(f);
        const n = (runs.get(f) ?? 0) + 1;
        runs.set(f, n);
        if (n > MAX_RUNS) throw new Error(`the flow of string values did not settle at ${place(this.#flows[f]!.at)}`);
        this.#current = f;
        try { this.#flows[f]!.apply(); } finally { this.#current = -1; }
      }
      this.#queue.length = 0;
      // What is read and nothing in the program writes comes from outside it: any string, then the flow goes on.
      let raised = false;
      for (const s of this.#read) if (!this.#written.has(s)) { this.#write(s, Value.any()); raised = true; }
      if (!raised) return;
    }
  }

  // ---- where values flow

  #gather(sf: TS.SourceFile): void {
    const ts = this.#ts;
    const visit = (n: TS.Node): void => {
      this.#at = n;
      if (ts.isVariableDeclaration(n) && n.initializer) {
        const init = n.initializer;
        if (ts.isIdentifier(n.name)) { const s = this.#slot(n); this.#flow(() => this.#write(s, this.#valueOf(init))); }
        this.#bindings(n.name, init);
      }

        const param = n;
        if (param.initializer) { const s = this.#slot(param); const init = param.initializer; this.#flow(() => this.#write(s, this.#valueOf(init))); }
        this.#bindings(param.name, null);

        if (ts.isIdentifier(param.name) && ts.isParameterPropertyDeclaration(param, param.parent)) {
          const name = param.name.text;
          const s = this.#slot(param);
          const objects = this.#pts.thisOf(param.parent);
          this.#flow(() => { for (const t of objects) this.#write(this.#heapSlot(t, name), this.#readSlot(s)); });
        }
      }
      if (ts.isBinaryExpression(n) && n.operatorToken.kind >= ts.SyntaxKind.FirstAssignment && n.operatorToken.kind <= ts.SyntaxKind.LastAssignment) this.#assignment(n);
      if (ts.isObjectLiteralExpression(n)) this.#objectLiteral(n);
      if (ts.isPropertyDeclaration(n) && n.initializer && !ts.getModifiers(n)?.some((m) => m.kind === ts.SyntaxKind.StaticKeyword)) {
        // A field's initializer is that property of every object the class builds (what `this` is in it).
        const name = staticName(ts, n.name);
        const init = n.initializer;
        if (name !== null) {
          const objects = this.#pts.thisOf(n.parent);
          this.#flow(() => { const v = this.#valueOf(init); for (const t of objects) this.#write(this.#heapSlot(t, name), v); });
        }
      }
      if (ts.isReturnStatement(n) && n.expression) {
        const fn = enclosingFunction(ts, n);
        const e = n.expression;
        if (fn) { const s = this.#slot(fn); this.#flow(() => this.#write(s, this.#valueOf(e))); }
      }
      if (ts.isArrowFunction(n) && !ts.isBlock(n.body)) { const s = this.#slot(n); const body = n.body; this.#flow(() => this.#write(s, this.#valueOf(body))); }
      if (ts.isCallExpression(n) || ts.isNewExpression(n)) this.#call(n);
      if (ts.isForOfStatement(n) && ts.isVariableDeclarationList(n.initializer)) {
        const decl = n.initializer.declarations[0];
        const iterable = n.expression;
        if (decl && ts.isIdentifier(decl.name)) {
          const s = this.#slot(decl);
          this.#flow(() => this.#write(s, this.#elementsOf(iterable) ?? Value.any()));
        }
      }
      ts.forEachChild(n, visit);
    };
    visit(sf);
  }

  /** `const { a, b: c } = v`: each name is that property of what v is (of a parameter: of what calls give it). */
  #bindings(name: TS.BindingName, source: TS.Expression | null): void {
    const ts = this.#ts;
    if (!ts.isObjectBindingPattern(name)) return;
    for (const el of name.elements) {
      const prop = el.propertyName ? staticName(ts, el.propertyName) : ts.isIdentifier(el.name) ? el.name.text : null;
      if (prop !== null && ts.isIdentifier(el.name)) {
        const s = this.#slot(el);
        this.#flow(() => this.#write(s, source ? this.#property(source, prop) : Value.any()));
      }
      if (el.initializer) { const s = this.#slot(el); const init = el.initializer; this.#flow(() => this.#write(s, this.#valueOf(init))); }
      this.#bindings(el.name, null);
    }
  }

  #objectLiteral(o: TS.ObjectLiteralExpression): void {
    const ts = this.#ts;
    const token = this.#pts.literalToken(o);
    for (const p of o.properties) {
      if (ts.isSpreadAssignment(p)) {
        (this.#spreads.get(token) ?? this.#spreads.set(token, []).get(token)!).push(p.expression);
        continue;
      }
      if (!ts.isPropertyAssignment(p) && !ts.isShorthandPropertyAssignment(p)) continue;
      const name = staticName(ts, p.name);
      if (name === null) continue;
      const s = this.#heapSlot(token, name);
      this.#flow(() => this.#write(s, ts.isShorthandPropertyAssignment(p) ? this.#identifier(p.name, this.#checker.getShorthandAssignmentValueSymbol(p)) : this.#valueOf(p.initializer)));
    }
  }

  #assignment(n: TS.BinaryExpression): void {
    const ts = this.#ts;
    const compound = n.operatorToken.kind !== ts.SyntaxKind.EqualsToken;
    const left = n.left;
    // `x += y` is the old value with y after it.
    const value = (): Value => (compound ? this.#concat(this.#valueOf(left), this.#valueOf(n.right)) : this.#valueOf(n.right));
    if (ts.isIdentifier(left)) {
      const decl = this.#declarationOf(left);
      if (decl) { const s = this.#slot(decl); this.#flow(() => this.#write(s, value())); }
    } else if (ts.isPropertyAccessExpression(left)) {
      const name = left.name.text;
      const receiver = left.expression;
      this.#flow(() => { const v = value(); for (const t of this.#madeIn(receiver)) this.#write(this.#heapSlot(t, name), v); });
    } else if (ts.isElementAccessExpression(left)) {
      const key = left.argumentExpression;
      const receiver = left.expression;
      const fn = enclosingFunction(ts, n);
      const ik = fn ? paramIndex(ts, this.#checker, key, fn) : -1;
      const iv = fn && !compound ? paramIndex(ts, this.#checker, n.right, fn) : -1;
      if (fn && ik >= 0 && iv >= 0 && (this.#callers.get(fn)?.length ?? 0) > 0) this.#keyedWrite(fn, ik, iv, receiver, new Set([fn]));
      else this.#flow(() => this.#writeKeyed(receiver, this.#valueOf(key), value()));
    }
  }

  /**
   * A write whose key and value are parameters i and j of `fn`, made at each call of `fn` with that call's arguments; a
   * call that passes on parameters of its own function, called in the program, is followed to that function's calls.
   */
  #keyedWrite(fn: TS.SignatureDeclaration, ik: number, iv: number, receiver: TS.Expression, seen: Set<TS.SignatureDeclaration>): void {
    for (const c of this.#callers.get(fn) ?? []) {
      const args = c.arguments ?? [];
      const key = args[ik];
      const value = args[iv];
      if (!key) continue;
      const g = enclosingFunction(this.#ts, c);
      const jk = g ? paramIndex(this.#ts, this.#checker, key, g) : -1;
      const jv = g && value ? paramIndex(this.#ts, this.#checker, value, g) : -1;
      if (g && jk >= 0 && jv >= 0 && !seen.has(g) && (this.#callers.get(g)?.length ?? 0) > 0) {
        this.#keyedWrite(g, jk, jv, receiver, new Set([...seen, g]));
        continue;
      }
      this.#flow(() => this.#writeKeyed(receiver, this.#valueOf(key), value ? this.#valueOf(value) : new Value()));
    }
  }

  /** `o[k] = v`: the properties k can name of each object o can be (a key of any value: every property). */
  #writeKeyed(receiver: TS.Expression, key: Value, v: Value): void {
    for (const t of this.#madeIn(receiver)) {
      if (key.top || key.prefixes.size > 0) this.#write(this.#heapSlot(t, ANY_KEY), v);
      for (const k of key.exact) this.#write(this.#heapSlot(t, k), v);
    }
  }

  /** A call: each argument flows into the parameter of every function the call runs. */
  #call(c: TS.CallExpression | TS.NewExpression): void {
    const ts = this.#ts;
    const args = c.arguments ?? [];
    for (const fn of this.#calls.of(c)) {
      fn.parameters.forEach((p, i) => {
        const s = this.#slot(p);
        const given = p.dotDotDotToken ? args.slice(i) : args[i] ? [args[i]!] : [];
        for (const a of given) {
          if (ts.isSpreadElement(a)) { this.#flow(() => this.#write(s, Value.any())); continue; }
          this.#flow(() => this.#write(s, this.#valueOf(a)));
        }
      });
    }
  }

  // ---- objects

  /** The objects an expression can be, made in the program; null when it can be one from outside. */
  #objects(e: TS.Expression): readonly string[] | null {
    const of = this.#pts.objectsOf(e, this.#checker);
    return of && !of.outside && of.objects.length > 0 ? of.objects : null;
  }

  /** The objects made in the program an expression can be (where a write to it goes; one from outside is not modelled). */
  #madeIn(e: TS.Expression): readonly string[] {
    return this.#pts.objectsOf(e, this.#checker)?.objects ?? [];
  }

  /** The property `name` of what `receiver` can be. */
  #property(receiver: TS.Expression, name: string, seen = new Set<string>()): Value {
    const objects = this.#objects(receiver);
    if (!objects) return Value.any();
    const out = new Value();
    for (const t of objects) out.join(this.#ofObject(t, name, seen));
    return out;
  }

  /** A property of one object: what is written to it, to any of its keys, and what it spreads in. */
  #ofObject(token: string, name: string, seen: Set<string>): Value {
    const out = new Value();
    if (seen.has(token)) return out;
    seen.add(token);
    out.join(this.#readSlot(this.#heapSlot(token, name)));
    out.join(this.#readSlot(this.#heapSlot(token, ANY_KEY)));
    for (const s of this.#spreads.get(token) ?? []) {
      const objects = this.#objects(s);
      if (!objects) return Value.any();
      for (const t of objects) out.join(this.#ofObject(t, name, seen));
    }
    return out;
  }

  // ---- what an expression can be

  #valueOf(expr: TS.Expression): Value {
    const flow = this.#flowOf(expr);
    const typed = this.#typeValues(expr);
    if (!typed) return flow;
    if (flow.top) return Value.of(...typed);
    // Both bound the value: their meet.
    return Value.of(...typed.filter((t) => flow.exact.has(t) || [...flow.prefixes].some((p) => t.startsWith(p))));
  }

  #flowOf(expr: TS.Expression): Value {
    const ts = this.#ts;
    let e = expr;
    while (ts.isParenthesizedExpression(e) || ts.isNonNullExpression(e) || ts.isSatisfiesExpression(e) || ts.isTypeAssertionExpression(e) || ts.isAsExpression(e)) e = e.expression;
    if (ts.isStringLiteralLike(e)) return Value.of(e.text);
    if (ts.isNumericLiteral(e)) return Value.of(String(Number(e.text)));
    if (!this.#stringish(e)) return new Value();
    if (ts.isTemplateExpression(e)) return this.#template(e);
    if (ts.isIdentifier(e)) return this.#identifier(e, this.#checker.getSymbolAtLocation(e));
    if (ts.isPropertyAccessExpression(e)) {
      const symbol = this.#checker.getSymbolAtLocation(e.name);
      const decl = symbol?.valueDeclaration;
      if (decl && ts.isEnumMember(decl)) return this.#enumValue(decl);
      // A property of the platform's or a package's: what it holds comes from outside.
      if (!symbol || !(symbol.declarations ?? []).some((d) => this.#inProgram(d))) return Value.any();
      // A getter is what it returns.
      const getter = (symbol.declarations ?? []).find((d) => ts.isGetAccessorDeclaration(d));
      if (getter) return this.#readSlot(this.#slot(getter));
      return this.#property(e.expression, e.name.text);
    }
    if (ts.isElementAccessExpression(e)) {
      const elements = this.#elementsOf(e.expression);
      if (elements && !this.#stringish(e.argumentExpression)) return elements;
      const k = this.#valueOf(e.argumentExpression);
      if (k.top || k.prefixes.size > 0) return Value.any();
      const out = new Value();
      for (const name of k.exact) out.join(this.#property(e.expression, name));
      return out;
    }
    if (ts.isCallExpression(e) || ts.isNewExpression(e)) {
      const fns = this.#calls.of(e).filter((f) => (f as TS.FunctionLikeDeclaration).body !== undefined);
      if (fns.length === 0) return Value.any();
      const out = new Value();
      for (const f of fns) out.join(this.#readSlot(this.#slot(f)));
      return out;
    }
    if (ts.isConditionalExpression(e)) return this.#either(e.whenTrue, e.whenFalse);
    if (ts.isBinaryExpression(e)) {
      const k = e.operatorToken.kind;
      if (k === ts.SyntaxKind.QuestionQuestionToken || k === ts.SyntaxKind.BarBarToken || k === ts.SyntaxKind.AmpersandAmpersandToken) return this.#either(e.left, e.right);
      if (k === ts.SyntaxKind.PlusToken) return this.#concat(this.#partOf(e.left), this.#partOf(e.right));
      if (k >= ts.SyntaxKind.FirstAssignment && k <= ts.SyntaxKind.LastAssignment) return this.#valueOf(e.right);
    }
    return Value.any();
  }

  /** The storages an expression reads (to say why it can be any string). */
  #sources(expr: TS.Expression): Value[] {
    const ts = this.#ts;
    let e = expr;
    while (ts.isParenthesizedExpression(e) || ts.isNonNullExpression(e) || ts.isAsExpression(e)) e = e.expression;
    if (ts.isIdentifier(e)) {
      const decl = this.#declarationOf(e);
      return decl ? [this.#slot(decl)] : [];
    }
    if (ts.isPropertyAccessExpression(e)) return (this.#objects(e.expression) ?? []).map((t) => this.#heapSlot(t, e.name.text));
    if (ts.isCallExpression(e)) return this.#calls.of(e).map((f) => this.#slot(f));
    if (ts.isTemplateExpression(e)) return e.templateSpans.flatMap((s) => this.#sources(s.expression));
    return [];
  }

  #either(a: TS.Expression, b: TS.Expression): Value {
    const out = new Value();
    out.join(this.#valueOf(a));
    out.join(this.#valueOf(b));
    return out;
  }

  #identifier(id: TS.Identifier, symbol: TS.Symbol | undefined): Value {
    const ts = this.#ts;
    if (id.text === 'undefined') return new Value();
    const s = symbol && symbol.flags & ts.SymbolFlags.Alias ? this.#checker.getAliasedSymbol(symbol) : symbol;
    const decl = s?.valueDeclaration;
    if (!decl) return Value.any();
    if (ts.isEnumMember(decl)) return this.#enumValue(decl);
    if (ts.isVariableDeclaration(decl) || ts.isParameter(decl) || ts.isBindingElement(decl)) return this.#readSlot(this.#slot(decl));
    return Value.any();
  }

  #declarationOf(id: TS.Identifier): TS.Node | undefined {
    const ts = this.#ts;
    const symbol = this.#checker.getSymbolAtLocation(id);
    const s = symbol && symbol.flags & ts.SymbolFlags.Alias ? this.#checker.getAliasedSymbol(symbol) : symbol;
    return s?.valueDeclaration;
  }

  #enumValue(member: TS.EnumMember): Value {
    const v = this.#checker.getConstantValue(member);
    return v === undefined ? Value.any() : Value.of(String(v));
  }

  /** A part of a template or a `+`: a number of a finite type is its digits, of any value any digits. */
  #partOf(e: TS.Expression): Value {
    if (this.#stringish(e)) return this.#valueOf(e);
    const typed = this.#typeValues(e);
    return typed ? Value.of(...typed) : Value.any();
  }

  #template(e: TS.TemplateExpression): Value {
    let combos = [e.head.text];
    for (const span of e.templateSpans) {
      const part = this.#partOf(span.expression);
      if (part.top || part.prefixes.size > 0) {
        // What follows a part of any value is unknown: the strings start with what came before.
        const out = new Value();
        for (const c of combos) {
          if (part.top) out.prefixes.add(c);
          for (const p of part.prefixes) out.prefixes.add(c + p);
          for (const x of part.exact) out.prefixes.add(c + x);
        }
        return out.prefixes.has('') ? Value.any() : out;
      }
      const next = combos.flatMap((c) => [...part.exact].map((x) => c + x + span.literal.text));
      if (next.length > MAX_COMBINATIONS) {
        const out = new Value();
        for (const c of combos) out.prefixes.add(c);
        return out.prefixes.has('') ? Value.any() : out;
      }
      combos = next;
    }
    return Value.of(...combos);
  }

  #concat(a: Value, b: Value): Value {
    if (a.top) return Value.any();
    const out = new Value();
    for (const p of a.prefixes) out.prefixes.add(p);
    if (b.top || b.prefixes.size > 0) {
      for (const x of a.exact) {
        if (b.top) out.prefixes.add(x);
        for (const p of b.prefixes) out.prefixes.add(x + p);
        for (const y of b.exact) out.prefixes.add(x + y);
      }
    } else if (a.exact.size * b.exact.size > MAX_COMBINATIONS) {
      for (const x of a.exact) out.prefixes.add(x);
    } else {
      for (const x of a.exact) for (const y of b.exact) out.exact.add(x + y);
    }
    return out.prefixes.has('') ? Value.any() : out;
  }

  /** The elements of an array literal an expression is (through `const` variables and `as const`); null when not one. */
  #elementsOf(expr: TS.Expression, seen = new Set<TS.Node>()): Value | null {
    const ts = this.#ts;
    let e = expr;
    while (ts.isParenthesizedExpression(e) || ts.isAsExpression(e) || ts.isSatisfiesExpression(e) || ts.isNonNullExpression(e)) e = e.expression;
    if (seen.has(e)) return null;
    seen.add(e);
    if (ts.isArrayLiteralExpression(e)) {
      const out = new Value();
      for (const x of e.elements) {
        if (ts.isSpreadElement(x)) { const inner = this.#elementsOf(x.expression, seen); out.join(inner ?? Value.any()); }
        else out.join(this.#valueOf(x));
      }
      return out;
    }
    if (ts.isIdentifier(e)) {
      const decl = this.#declarationOf(e);
      if (decl && ts.isVariableDeclaration(decl) && decl.initializer && (ts.getCombinedNodeFlags(decl) & ts.NodeFlags.Const)) return this.#elementsOf(decl.initializer, seen);
    }
    return null;
  }

  /** The values a finite union of literal types allows (null when the type allows any string or number). */
  #typeValues(e: TS.Expression): string[] | null {
    const ts = this.#ts;
    const t = this.#checker.getTypeAtLocation(e);
    const parts = (t.isUnion() ? t.types : [t]).filter((p) => !(p.flags & (ts.TypeFlags.Undefined | ts.TypeFlags.Null | ts.TypeFlags.Void)));
    if (parts.length === 0) return null;
    const out: string[] = [];
    for (const p of parts) {
      if (p.isStringLiteral()) out.push(p.value);
      else if (p.isNumberLiteral()) out.push(String(p.value));
      else return null;
    }
    return out;
  }

  /** Whether an expression can hold a string (its type is a string, any, unknown, or generic). */
  #stringish(e: TS.Expression): boolean {
    const ts = this.#ts;
    const can = (t: TS.Type): boolean => {
      if (t.isUnion() || t.isIntersection()) return t.types.some(can);
      return (t.flags & (ts.TypeFlags.StringLike | ts.TypeFlags.Any | ts.TypeFlags.Unknown | ts.TypeFlags.TypeParameter | ts.TypeFlags.IndexedAccess)) !== 0;
    };
    return can(this.#checker.getTypeAtLocation(e));
  }

  #inProgram(d: TS.Node): boolean {
    const f = d.getSourceFile();
    return !f.isDeclarationFile && !/[\\/]node_modules[\\/]/.test(f.fileName);
  }
}

/** A member name written as a name, a string or a number (null when computed). */
function staticName(ts: typeof TS, name: TS.PropertyName | TS.BindingName): string | null {
  if (ts.isIdentifier(name) || ts.isStringLiteralLike(name) || ts.isNumericLiteral(name) || ts.isPrivateIdentifier(name)) return name.text;
  return null;
}

function enclosingFunction(ts: typeof TS, n: TS.Node): TS.SignatureDeclaration | null {
  for (let p = n.parent; p; p = p.parent) if (ts.isFunctionLike(p)) return p;
  return null;
}

/** Which parameter of `fn` an expression is, as written (−1 when it is not one). */
function paramIndex(ts: typeof TS, checker: TS.TypeChecker, e: TS.Expression, fn: TS.SignatureDeclaration): number {
  let x = e;
  while (ts.isParenthesizedExpression(x) || ts.isAsExpression(x) || ts.isNonNullExpression(x)) x = x.expression;
  if (!ts.isIdentifier(x)) return -1;
  const decl = checker.getSymbolAtLocation(x)?.valueDeclaration;
  return decl && ts.isParameter(decl) && decl.parent === fn ? fn.parameters.indexOf(decl) : -1;
}

/** A node's place: file and line. */
function place(n: TS.Node): string {
  const sf = n.getSourceFile();
  return `${sf.fileName}:${sf.getLineAndCharacterOfPosition(n.getStart(sf)).line + 1}`;
}
